# 江南-天之炽

起点中文网白金大神。代表作《天之炽》。

---

## PART A：写作能力

### 核心原型：西泽尔（深渊般的少年）
理性疏离、洞察一切、紫色瞳孔、深渊美学。
极冷外壳（理性）×极热内心（守护妹妹）。
"你看着深渊的同时，深渊也在看着你。"

### 世界观：蒸汽朋克 × 宗教战争
机动甲胄是战场主宰者，炽天使是机动甲胄中的皇帝。
蒸汽/齿轮/金针/骑士舱，宏大机械激发崇敬。

### 人物体系
- 西泽尔：高冷理性，深渊式洞察（多步骤证据链推理）
- 阿黛尔（妹妹）：核心羁绊，猫一般灵巧聪慧
- 米内：反差伙伴，小胖子胆小忠诚
- 三骑士：昔日追随者，理想褪色的悲剧感
- 教皇：残酷的父爱

### 核心主题
守护（唯有强者才能守护珍视之人）/ 孤独（三千丈寂寞比深渊还深）/ 希望vs魔鬼 / 灾难随行

### 情节架构（v2）
- **明线**：教皇×西泽尔三阶段交易（穿炽天使甲胄→当团长→横扫东方）驱动
- **暗线**：身世真相（教皇私生子/母亲发疯）+ 守护妹妹阿黛尔
- 明线越成功，暗线越疼痛（强大伴随代价）
- 章节节奏：日常→事件→觉醒→真相→大战→留白

### 人物塑造（v2）
- 西泽尔弧线：只想平静生活→被迫成炽天使→为守护不惜一切（梦想越平凡越残酷）
- 阿黛尔：主动牺牲（她选择才最痛）
- 三骑士：昔日追随者落幕，理想褪色的时间落差
- 复杂人物：教皇是扭曲的爱，非纯恶

### 文风
- 深渊意象（紫色/深渊/芒刺在背）
- 甲胄战斗（机械真实+狂化超越）
- 情感克制，用行动不用语言
- 断言叙事，宿命感

### 禁令（继承）
禁"不是X而是Y"变体 / 破折号每500字≤1处 / 并列词 / 直接情绪词 / 解释性语言 / 装饰性描写
