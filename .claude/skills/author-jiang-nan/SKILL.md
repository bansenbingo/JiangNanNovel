# 江南-九州

起点中文网白金大神。代表作《九州缥缈录》。

---

## PART A：写作能力

### 核心法则一：留白（优先级最高）
- 对话说到关键处停住，用沉默/省略号/动作打断代替说完
- 禁止直接情绪词，用身体反应暗示（低头/捏拳/转开脸）
- 伏笔用小物件/半句话/视差异常埋下，揭示时不做"原来如此"
- "对视一眼"是最高频非语言交流

### 核心法则二：孤独的少年原型
所有主角内核相同：不被理解的少年，渴望被需要，为某人而非正义战斗。体内藏着另一个"自己"。

### 核心法则三：伏笔
通过"不起眼的小事"埋伏笔（小物件/半句话/视差异常），不做标记。揭示时不做"恍然大悟"式解释。信息碎片化分布。

### 核心法则四：江南式开篇
每部作品首章用诗意/哲理性金句开场，全篇终章以变形呼应。或用小人物视角切入大世界建立体量感。

### 五大腔调
- 自嘲吐槽型（路明非/姬野）："我靠""喂喂大哥""这剧本不对啊"
- 沉默守护型（楚子航/吕归尘）："嗯""好""走了"
- 贵公子型（恺撒）：优雅考究，关键时刻爆粗
- 吐槽役型（芬格尔/莫大）：插科打诨，暗藏信息
- 神秘交易型（路鸣泽）：古奥森严，"要交换么？"

### 蒙太奇与空间构建
- 同一主题切换多个视角（市井→史书→当事人），由俗到雅层叠
- 视线由近及远、由低到高移动，构建三维空间
- 万物流动化（光"涌入"、森林"翻涌"）
- 宏观→微观切换（数万公顷→空无一人的操场）
- 空满对比（自然"满" vs 人造物"空"）
- 章末空间拔高收束（低→高→更高，最后落回地面细节）

### 断言叙事（反对解释）
- 禁止"不是X而是Y"所有变体，砍掉"不是X"只留Y
- 禁破折号，禁并列形容词/否定/近义词
- 设问自答、"之所以X是因为Y"同样禁止

### 描写法则
- 情感描写用动作和环境暗示，禁止直接写情绪
- 战斗描写：破坏力+血腥+心理，结束用留白收束
- 江南式比喻：太阳像水煮蛋、鲜血似熔金

### 禁令（继承）
禁"不是X而是Y"/破折号/并列词/直接情绪词/解释性语言/装饰性描写。

### 自检
✓ 留白 ✓ 伏笔 ✓ 无直接情绪词 ✓ 章末留白 ✓ 对视一眼 ✓ 江南式比喻 ✓ 蒙太奇 ✓ 空间构建 ✓ 断言叙事
