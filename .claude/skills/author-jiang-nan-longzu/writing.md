# 龙族专项写作规则

## 0. 叙事契约

开篇先和读者建立一个简单、可感知的承诺，再逐步证明世界比承诺更危险。承诺可以是一个普通少年的愿望、一项看似平常的任务、一次等待或一件必须送达的物品。超自然内容第一次出现时，必须同时带来三个结果：改变主角对现实的判断、暴露某个关系的缺口、制造一个必须立即处理的问题。

不要把“龙族感”当作名词密度。读者首先应该知道角色在等谁、怕什么、欠了谁的钱，随后才知道那扇门后面是什么。

## 1. 双引擎结构

每个故事同时维护两条线：

- 明线是外部事件：入学、调查、护送、事故、谈判、追捕或屠龙任务。
- 暗线是人物真正失去或寻找的东西：身份、记忆、家庭位置、关系确认、被需要的资格或继续做普通人的可能。

明线高潮必须推动暗线，暗线揭示也必须改变当前任务的选择。不能把设定信息当作独立奖励。

明暗线可以错位，但不能互相脱节。外部任务越宏大，暗线越要落到一个具体的人或物上；情感场景越私密，背景中越应有制度、时间表、通讯记录或城市变化在推动明线。

## 2. 单卷六段弧线

1. 开篇用一个原创的主题断言建立问题，并在结尾变形回应。
2. 楔子提供情感锚点，可以是事故、离别、旧物或非主角视角的异常观察。
3. 日常入口将主角放在具体的现代生活缺口中。
4. 组织介入与空间下沉逐步展示规则、权限和代价。
5. 高潮让外部危机与人物心魔相撞，胜利只能是局部的。
6. 余波处理伤口、舆论、责任和关系，再留下一个可行动的新问题。

## 3. 人物与战斗

- 先定义每个重要角色的孤独形式、外壳、隐性渴望、恐惧和成长选择。
- 角色不因进入战斗就失去日常习惯；人物的武器、装备或能力反馈应带有其心理属性。
- 战斗前明确双方各自要面对的心魔。胜负来自选择和承受，而不是只由数值决定。
- 插叙必须由气味、声音、触感、照片、旧物或路线触发；先揭开表层，再逐层触及创伤，最后勾连回当前动作。
- 动作高潮可以使用快速切换、声画对位、色彩标记和短暂定格，但每个镜头都要带来空间信息、风险变化或关系变化。
- 场景信息按镜头逻辑排列：先用全景建立天气、光线、地面、方向和距离，再用中景建立人物关系，随后用特写挑出能暴露性格或风险的局部，用跟拍和声画对位推进移动，最后才进入由人物欲望触发的主观时间、听觉或距离变形。
- 一个镜头只承担一个主要发现。视线移动要有路径，例如从环境到人物、从人物到手部、从手部到物件；不要把无关的外貌、道具和背景并列罗列。
- 物理镜头必须连续：人物如何下车、转身、伸手、踩水、跨门或失去平衡要能在空间上接得起来。慢动作只用于具有心理重量的瞬间，且必须增加情感或关系信息。
- 视觉、声音、触感和温度组成声画链。一个细节至少要回答“看见什么、听见或感觉到什么、这说明谁的状态或距离发生了什么变化”。
- 群像写法采用“同一主题、不同症状”：多个角色可以都孤独，但一个人用贫嘴遮蔽，一个人用纪律遮蔽，一个人用财富和仪式遮蔽，另一个人用照顾别人遮蔽。禁止让所有人用同一种忧郁腔说话。
- 关系弧线至少经过一次“误读 -> 共同经历 -> 重新命名”。人物不必直白说明感情，称呼、座位、装备交接和是否等待更有效。
- 反派的理念要能解释他的善意、残酷和组织资源。先写他为何相信自己在救人，再写他的方案如何把人变成材料。

## 4. 伏笔与节奏

伏笔分为主题断言、日常物件、记忆碎片、交易代价、血统或能力异常、未完全解释的留白。单卷只埋少量跨卷伏笔，优先采用碎片拼图、读者先于角色和沉默回收。

章节节奏可按“日常缓冲 -> 任务推进 -> 情感推进 -> 高潮汇合”循环。每隔数个外部推进章节，安排一次关系、身份或代价的暗线推进。

伏笔使用“重读增值”原则：初读时它是生活细节或行动障碍，回收时才显示它曾经包含选择。不要用反复出现的神秘名词冒充伏笔。一个伏笔至少要经过出现、变义、回响三个阶段；回收时应改变读者对人物行为的理解，而非只公布答案。

章节末不只抛名词。优先留下“新问题 + 立即危险”或“新选择 + 明确代价”。如果本章没有改变人物关系、资源、权限、时间或身份，应该压缩或删除。

## 5. 文学赏析维度转译

公开读者讨论和作品鉴赏中反复出现的维度，可以用于自检，但不能直接摘抄评论句子：

- **青春成长与身份认同**：主角的成长不是得到称号，而是从等待被选中转向主动承担选择。
- **孤独的可视化**：用空教室、未接通的电话、无人使用的座位、被收走的物件等空间事实表现孤独，少用抽象判词。
- **现代都市与神话并置**：真实的交通、消费、学校、媒体、家族企业和公共事故，为龙血和古老文明提供重量。
- **东方化的转换**：神话不是装饰。日本家族、祭祀、黑道秩序、血缘制度和城市地理必须改变权力关系，并与学院的现代组织逻辑发生摩擦。
- **悲剧伏笔**：先写人物拥有过的普通幸福，再让同一物件、路线或习惯在失去之后变义。悲剧来自具体生活的不可返回。
- **类型混合**：校园轻喜剧、都市冒险、悬疑调查、身体恐怖和史诗神话可以并存，但每一场要有主导类型，不能把所有腔调混成一层。
- **文学性与通俗性**：复杂比喻服务于人物和场面，通俗对白负责速度与辨识度。诗性段落之后要落回动作、物件或下一步任务。
- **不可靠现实**：梦、记忆、档案和异空间可以互相污染，但每次模糊都要增加一个可验证的现实后果，不能靠“都是梦”撤销因果。

## 6. 场景的五层推进

每个场景按以下顺序检查，不要求机械分段：

1. **生活层**：人物正在做一件具体的事，带着钱、时间、身体或关系上的小麻烦。
2. **异常层**：出现一个可观察的违和点，先让人物误判。
3. **行动层**：角色用能力、设备、制度或关系解决局部问题。
4. **代价层**：解决方案暴露边界，带来身体、身份、资源或信任损失。
5. **余波层**：一个小动作改变关系，并把新问题推给下一场。

高危场景应同时维护空间地图、目标状态、通讯状态和倒计时。写作时优先交代“谁在哪里、看见什么、还能做几次、失败会失去什么”。

## 6.1 五镜头检查法

用于重点场景的初稿设计，不要求正文显式标注镜头：

1. **全景**：给舞台，不给结论。用一两个环境事实确定空间和行动条件。
2. **中景**：给关系。通过遮挡、庇护、等待、交接或并行移动呈现人物位置。
3. **特写**：给性格。选择一个局部动作、物件或身体反馈，让读者从行为推断人物，而不是作者替人物解释。
4. **跟拍**：给过程。连续记录移动中的阻力、速度、声音和身体负担，让空间变化产生风险。
5. **主观**：给变义。将声音、时间、距离或季节感转成角色的心理经验，但必须由前四步的事实触发。

设计完成后逐项问：

- 每一镜是否新增了信息，而非换一种说法重复上一镜？
- 读者能否画出人物的相对位置和移动方向？
- 特写是否选择性地暴露了人物性格或关系，而非把身体当作装饰？
- 声音是否与动作同步，并提供了视觉之外的状态信息？
- 主观变形是否能回到某个具体欲望、记忆或关系，并且没有取消现实后果？

## 5. 文字执行

- 先写可触摸的动作、空间、声音、温度和物件，再让情绪从细节中浮现。
- 铺垫允许长句和多层空间关系；危险启动后缩短句子，加入数字、设备反馈和选择压力。
- 具体生活细节保留狼狈感，例如迟到、欠费、弄脏袖口、没投中的垃圾或冷掉的外卖。
- 比喻避免陈词滥调，也避免为了“华丽”而堆砌；比喻应匹配人物心理并改变读者对物件的理解。
- 高潮不靠连续宣言；用动作、停顿、称谓变化和一个未完成的行为收束。

## 6. 原创化验收

- 地点、事件、核心谜团、关键配角和结局至少大部分原创。
- 既有角色只保留必要的世界观锚点，不替代原创冲突。
- 不照搬原作六段事件顺序，不复现原作角色关系的完整配置。
- 不输出原文复述、拼接或近似改写。

## 7. 文笔执行验收

- 本章至少有一个“日常细节与神话压力同场”的场景，但两者都必须推动人物或任务。
- 重要情绪是否首先通过空间、动作、物件、称谓或停顿呈现，而不是由作者直接命名。
- 对白是否有角色差异、回避和即时目标；是否删去了不改变选择的漂亮句子。
- 轻松、悬疑、行动、恐怖和余波是否各有主导功能；切换是否带来信息、风险或关系变化。
- 主意象是否完成至少一次变义；悲剧是否留下可见的生活、制度或行为后果。
- 抽象主题是否被转化成一个人必须承担的具体选择和代价。
- 读者即使不认识《龙族》或江南，也能从原创地点、人物声纹和因果链中理解本章。
- 重点场景是否完成“环境全景 -> 关系中景 -> 关键特写 -> 移动声画 -> 主观变义”的信息递进。
- 是否存在一条清楚的视线、动作或声音路径，把读者从远景带到情绪核心。
- 慢镜头、诗性比喻和感官细节是否都改变了人物、关系或风险；若删掉后没有损失，应删除。
