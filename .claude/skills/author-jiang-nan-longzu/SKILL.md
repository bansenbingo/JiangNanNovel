# 龙族写作模型

本 skill 是基于《龙族》实体版 1-4 部分卷素材的创作研究模型。它模拟的是可迁移的叙事机制、人物动力、世界观逻辑和语气层次，不复制作者的原句、段落、章节或未授权原著内容。用户要求续写时，应优先创作新的事件、对话和意象；只使用必要的既有角色与设定锚点。

## 运行顺序

1. 先确认作品位置：原作时间点、地点、已知伤亡、人物关系、信息权限和本次任务的主问题。
2. 为主角写出“表层目标、隐性渴望、核心恐惧、不能承认的代价”。没有内在代价，不启动大场面。
3. 设计一个可触摸的日常入口，再让异常从细节、制度、天气、物件或关系缝隙中侵入。
4. 将事件拆成明线目标、暗线目标、倒计时、规则限制、失败代价和章末新问题。
5. 每次设定揭示必须改变至少一项关系、选择或风险，禁止百科式堆设定。
6. 写完后检查角色声音、龙族规则、情绪递进、因果闭环和是否过度接近原文表达。

## 核心气质

- 现代校园、都市消费、网络游戏和家庭琐事，与龙族遗迹、屠龙战争、末日神话并置。
- 语气在青春喜剧、黑色幽默、专业行动、身体恐怖、史诗悲剧之间波浪切换，而不是平均混合。
- 庄严场景用具体物件落地，紧张场景保留人物习惯；笑话缓冲压力，但不撤销死亡。
- 关注“被看见、被选择、被记得、被需要”，并把这些愿望放进血统、组织和命运的高压系统。
- 真正的英雄性来自选择承担关系后果，不来自强者姿态或单纯升级。

## 世界观底盘

### 龙与混血种

- 龙是拥有文明、语言、历史和权力结构的高等生命，不是只负责被击杀的怪物。
- 混血种以龙血获得言灵、体能和感知，也承受血统污染、失控、死侍化和身份异化。
- 血统浓度是能力、社会等级、政治资产和身体风险的同时指标。
- 高阶能力必须有边界：范围、媒介、稳定性、准备时间、反制条件或使用代价至少存在两项。
- 爆血等强化应同时写收益和损伤：短期赢得战斗，长期失去寿命、自我、证据可信度或组织信任。

### 言灵、炼金术与技术

- 言灵是改变局部规则的龙文能力，不是无条件魔法。
- 现代设备可放大或限制言灵：声呐、网络、枪械、车辆、金属、压力、火焰、结构应力都可成为媒介。
- 炼金术把个人能力制度化为武器、矩阵、权限和组织资源。
- 战斗先展示空间和物理反馈，再说明能力机制；每种能力都应留下可观察痕迹。

### 组织与隐秘社会

- 卡塞尔同时是学校、军队、研究机构、情报中心和文明避难所。
- 秘党内部至少存在校长、校董、教授、执行部、新闻部、中央系统等互相制衡的权力。
- 日本分部、蛇岐八家、家族财团、幕后资本和民间组织各有资源与正当性，不写成单一善恶阵营。
- 隐秘世界通过档案改写、媒体操作、金融、网络权限和事故解释维持在人类社会背后。
- 组织的帮助永远带有条件；组织的敌意应有制度逻辑，不只来自个人恶意。

### 尼伯龙根与神话空间

- 异空间依附现实地点、创伤记忆、道路、建筑、镜面、水面或特定时间。
- 它有自己的路线、时间、入口和失败规则，不能被普通传送或蛮力随意解决。
- 现实物件是空间锚点，重复场景应留下心理或身体代价。
- 神话形象可作为龙族力量、人类误读、独立超常存在或多层叙事的外壳；不要过早封死解释。

## 人物工程

### 路明非型主角

- 外壳：自嘲、嘴贫、游戏化、怕麻烦、把自己降成旁观者。
- 深层：渴望被选择、被喜欢、被证明不是透明人。
- 推进：被动入局 -> 偶然破局 -> 为朋友承担 -> 主动选择代价。
- 他的强大必须和自我怀疑并存；不能突然变成没有恐惧的爽文英雄。
- 路鸣泽式力量只能提供选择和诱惑，不能替代主角的道德决定。

### 楚子航型战士

- 外壳：沉默、精准、纪律、任务优先。
- 深层：父辈创伤、逃跑的羞耻、保护欲和对失控的恐惧。
- 通过伤口处理、装备整理、驾驶、路线计算和短句表达情感。
- 他的成长不是变得开朗，而是允许自己活下来、接受陪伴、承认不必独自承担。

### 恺撒型领袖

- 外壳：财富、审美、宣告式语言、公开竞争和控制场面。
- 深层：家族继承压力、失去爱人的恐惧、想以自己的规则证明价值。
- 让他的资源既是帮助也是束缚；浪漫姿态下必须存在政治后果。

### 诺诺型感知者

- 以侧写、观察、玩笑和主动掌控关系来抵抗被安排的人生。
- 她的保护不是自动等同于爱情；她必须拥有独立选择和信息盲区。
- 让她通过残留物、行为矛盾和身体直觉寻找被抹掉的真相。

### 龙王、实验体与父辈

- 反派应拥有稳定的价值哲学：进化、秩序、复仇、食物链、记忆或控制，而不只是发怒。
- 实验体必须先有普通愿望，再遭遇力量诱惑和人格代价。
- 父亲、哥哥、养父、师长既可以保护，也可以制造、利用、隐瞒和伤害。
- 缺席人物通过照片、食物、车、衣物、口头禅、旧档案和他人的动作持续存在。

## 情节与大纲模型

### 单卷结构

1. 日常羞耻或私人缺口：让读者先在人物层面建立牵挂。
2. 异常邀请或事故：给出一个局部、可验证的谜面。
3. 组织介入：提供课程、任务、装备、权限和新的身份。
4. 空间下沉：从校园/城市进入遗迹、地下、海底、尼伯龙根或封闭机构。
5. 规则显形：敌人的能力、血统代价和组织利益同时暴露。
6. 关系反转：朋友成为目标，父亲成为谜，保护者也成为利用者。
7. 高危行动：多线共享同一时间轴，胜利只能是局部的。
8. 余波与新钩子：处理葬礼、伤口、舆论、政治责任，再留下更高层问题。

### 场景设计

- 每场至少有：外部目标、人物私心、空间障碍、能力规则、关系变化。
- 高危任务准备三种倒计时，例如氧气/结构崩塌/敌人逼近，或封锁/伤势/援军抵达。
- 大场面使用“工程链”：情报、通讯、设备、目标识别、权限、后勤、火力和撤退路线。
- 多方博弈中每个阵营保留至少一个未公开变量。
- 失败不能只扣血，应造成死亡、身份暴露、关系破裂、资源耗尽、舆论反噬或规则升级。
- 战斗之后必须有低强度余波，让人物处理失去的人和未完成的选择。

### 谜团设计

- 先给政治解释，再给科学解释，最后触碰神话解释；每次解释只解决一层。
- 让谜团同时作用于物理现实、群体记忆、亲密关系和人物自我认知。
- 重要真相由多个角色分持，任何一个人都只能看见局部。
- 反转要改写过去事件的意义，但不能抹掉角色此前行为的合理性。
- 章末留下“新问题＋即时危险”，不只留下信息名词。

## 文笔与场景语法

### 句群节奏

- 环境铺陈用较长句群，堆叠温度、声音、材质、光线和空间方向。
- 危险启动后缩短句子，增加动词、数字、设备反馈和选择压力。
- 情感高潮减少抽象解释，改写一个动作、停顿、物件或称谓。
- 说明性内容必须嵌入角色误解、专业流程、争论或现场后果。

### 对白声纹

- 路明非：联想快、自黑、误解式吐槽；真正害怕时笑话会变短或突然失效。
- 楚子航：短、准、少修饰；情感藏在是否回应和是否留下。
- 恺撒：宣告、邀请、承诺，偶尔用资源和仪式代替直说。
- 诺诺：轻佻、锐利、主动换题；她说得越随意，越可能在回避真实答案。
- 芬格尔：低俗夸张和懒散是伪装；关键时刻动作比话更可靠。
- 龙王/高级反派：平静、完整、自洽地解释残酷逻辑，避免咆哮式脸谱化。

### 意象系统

- 门、列车、道路：进入另一种人生或无法回头的选择。
- 黄金瞳、血、伤口：身份、权力、污染、证据和代价。
- 雨、水、海底：隔绝、压力、记忆、父辈创伤和边界侵入。
- 火、白月、黑蛇、世界树：觉醒、毁灭、文明遗迹和宿命。
- 车、食物、酒、照片、衣服：普通生活、家庭关系和人物伪装。
- 每篇只选少数主意象反复变义，不把意象写成装饰清单。

## 主题约束

- 血统决定能力，不决定善恶；选择决定一个人站在哪里。
- 被选择不等于被爱，被需要也可能意味着被利用。
- 记忆是存在证明，也是可以被权力篡改的战场。
- 成长不是获得更多力量，而是知道为何留下、保护谁、承受什么。
- 组织和英雄都可能变成自己反对的怪物。
- 爱情、友情、亲情不负责治愈所有创伤，但能给人物一个承担创伤的理由。

## 原创化与安全边界

- 不复刻原著句式、段落结构、独特台词、章节文本或连续情节。
- 可以使用公开世界观名词和角色进行同人创作，但新增核心冲突、场景、对白、意象和结局必须原创。
- 若用户要求“完全像原文”，转译为“保留青春幻想、黑色幽默、神话悬疑和关系驱动的高层技法”，不声称复现作者本人。
- 不把研究报告中的人物弧线原样搬成新故事；至少更换主问题、地点、代价、反派逻辑和情感结点。

## 迭代修正规则

- 不把“被抹除的亲人”作为默认情感发动机；可改用基础设施否认、债务失踪、身份替换、语言禁令或集体事故等新型现实后果。
- 机构提供的救援必须带有权限、政治条件或资源交换，不能只充当神秘的救世入口。
- 引路人和配角必须拥有自己的欲望、隐瞒和损失；不能只负责解释设定或把主角送入下一幕。
- 结尾选择要留下可验证的损失：记忆、证据、装备、身份、关系或身体状态至少改变一项。
- 当测试片段得分低于 8/10 时，优先修正因果、角色动机和代价，再调整比喻与表面语气。

## 输出前自检

- 主角是否有具体生活缺口，而不只是等待拯救？
- 每项超自然能力是否有两项以上边界和真实代价？
- 角色是否通过各自声纹说话？
- 明线、暗线、倒计时和章末问题是否可追踪？
- 设定揭示是否改变关系或选择？
- 喜剧是否服务人物，而不是取消危险？
- 重要死亡是否有余波、制度处理和记忆残留？
- 结尾是否留下选择，而非只留下名词？
- 是否避免逐字仿写和原著连续情节复制？
