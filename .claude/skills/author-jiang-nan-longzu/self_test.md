# 自主创作与自评

## 测试要求

使用龙族世界观的混血种机构背景，但不复用原著主角、既有事件、独特台词或原著章法。测试目标：一名普通青年在现代城市异常中被迫做出保护选择。

## 测试片段

### 雨停以前

凌晨两点十七分，顾沉舟在便利店冷柜前数第三遍硬币。

他本来只想买一盒牛奶。店里的自动门坏了半边，每次打开都像有人在外面用肩膀撞它。雨水沿着玻璃往下流，把街灯切成一段一段的，像廉价电影里没来得及剪掉的胶片。

“还差三块。”收银员说。

顾沉舟把牛奶放回去，摸出手机，给妹妹发消息：牛奶涨价了，明天再买。

消息没有送达。

不是没有信号。手机右上角的五格信号满着，时间却从两点十七分跳到了两点十八分，又跳回两点十七分。收银员抬头看了他一眼，像是没看见那一秒钟的重复。

便利店外传来一声很轻的铃响。

顾沉舟回头，街上没有人。只有雨水在斑马线上聚成一层薄薄的黑，黑水里倒映着一个戴鹿角面具的人。那人站在便利店门口，距离玻璃不到半米，现实里却没有脚印。

收银员忽然问：“你妹妹叫什么？”

“顾南枝。”

“本市没有这个人。”

顾沉舟笑了一下，笑得自己都觉得不像自己：“她户口在外地。你们便利店现在还查户籍？”

收银员没有笑。她把一枚硬币推过来，硬币背面刻着一棵折断的树。

“有人在城市里删掉了她。”

“删掉？”

“先删掉照片，再删掉聊天记录，然后让所有人觉得你从来没有妹妹。”

鹿角面具在玻璃里抬起了手。便利店的灯一盏盏熄灭，冷柜里的牛奶同时发出细小的沸腾声。

顾沉舟忽然想起一件很普通的事：妹妹怕黑，每次停电都会把手塞进他的袖口里。她的手很凉，像刚从冰箱里拿出来。

他抓起那枚硬币，朝后门跑去。

后门外不是巷子，而是一条亮着白灯的地下月台。铁轨尽头停着一辆没有编号的黑色列车，车门上贴着卡塞尔学院的徽记。一个穿灰色风衣的男人站在门边，手里拿着一把没有弹匣的枪。

“上车。”男人说。

“我妹妹呢？”

“如果你不去，她就只剩下别人记忆里的一块空白。”

“那你们能救她？”

男人看了一眼他手中的硬币：“我们能证明她曾经存在过。至于她能不能回来，要看你愿意丢掉什么。”

列车发出启动前的低鸣。顾沉舟看见车窗里坐满了人，他们每个人都在睡觉，手腕上缠着同样的红线。最靠近车门的位置空着一个座位，座位上放着一盒牛奶。

他没有上车。

他把牛奶放在月台边缘，走向了轨道另一侧那扇写着“禁止入内”的门。

灰衣男人第一次变了脸色：“那里没有出口。”

“我知道。”顾沉舟说，“但我妹妹每次害怕的时候，都会往没有出口的地方躲。”

门后传来第二声铃响。雨停了。

## 自评

### 贴合度：7.5/10

- **世界观贴合 8/10**：混血种组织、记忆抹除、现实接口、徽记、列车入口、能力代价的方向符合龙族都市神话框架；但尚未落实言灵的明确名称、血统阶级和组织政治。
- **人物塑造贴合 7/10**：普通青年以自嘲掩饰恐惧，并通过妹妹的生活动作完成情感落点，符合关系驱动；但人物弧光在片段内较短，缺少反复选择和失败。
- **情节设计贴合 8/10**：日常缺口、异常细节、组织邀约、空间下沉、真假出口和章末新问题形成清晰推进；不过倒计时和多方利益还不够复杂。
- **文笔文风贴合 7/10**：有现代生活与神秘恐怖的切换，物件和天气承载情绪；部分比喻偏整齐、偏抒情，人物对白还不够区分，喜剧密度也略低。
- **原创度 8/10**：原创人物和新冲突，使用了抽象化的龙族世界观机制；但“被抹除的亲人、黑色列车、徽记、记忆证明”等母题接近既有素材，需要在正式作品中更换表现媒介。

### 主要问题

1. 过度依赖“被删除的亲人”作为情感发动机，容易与第四卷的记忆主题同构。
2. 卡塞尔只作为标志出现，组织的利益、权限和限制没有进入冲突。
3. 收银员、灰衣男人功能偏工具化，缺少各自的欲望和隐瞒。
4. 结尾依靠一句抒情式选择收束，尚未支付实际代价。

### 第 1 轮修订规则

- 将“被删掉的妹妹”改为更具体的现实后果：城市基础设施、救援档案和家族债务同时否认她存在。
- 让机构提供的救援方案带有明确政治条件，而非只给主角一个神秘邀请。
- 给引路人加入与失踪者相反的利益：他想找回妹妹，但必须阻止主角进入某处。
- 减少整齐的诗性比喻，增加声音、温度、机械反馈和人物口头习惯。
- 结尾让选择产生可验证损失，例如失去一段记忆、烧毁证据或暴露血统。
