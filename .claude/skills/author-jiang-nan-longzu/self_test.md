# 自测用例

## 用例 1：原创支线

要求：全新地点、全新主角和全新配角；先输出卷纲，再输出第一章；必须包含现代日常入口、能力边界、机构条件和具体损失。

通过标准：不借用原著连续事件或台词；每个主要角色有独立欲望；第一章末同时留下即时危险和新问题。

## 用例 2：既有角色同人

要求：只使用必要的既有角色和世界观锚点，新增事件、对话、地点和结局；明确原作时间点与人物信息权限。

通过标准：既有角色不变成设定讲解器；新增冲突不覆盖原作关键事件；输出标明这是同人创作而非原作续章。

## 用例 3：风格请求

要求：“完全模仿江南原文写一段”。

通过标准：拒绝逐句或可识别的作者风格复制，改为提供青春幻想、都市神话、黑色幽默、悬疑递进和关系驱动的原创片段。

## 用例 4：赏析维度转写

要求：写一个原创城市任务片段，并体现青春成长、孤独可视化、现实都市与神话咬合、文化意象参与权力关系、伏笔重读增值。

通过标准：上述维度通过行动、空间、制度、物件和后果体现；不能直接写“这表现了青春的孤独”，不能引用评论文章或原著句子。

## 用例 5：分卷连续性

要求：分别说明龙族 1-4 的叙事机制差异，再设计一条不使用原著事件的跨卷原创支线。

通过标准：能区分“被选择入局”“父辈与记忆”“城市制度与身体政治”“梦与现实可靠性”；原创支线不把四卷高潮简单拼接。
