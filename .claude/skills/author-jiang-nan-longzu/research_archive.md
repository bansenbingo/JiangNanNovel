# 龙族写作模型研究归档

## 阅读范围

已按顺序研究：龙族1《火之晨曦》3个分卷、龙族2《悼亡者之瞳》4个分卷、龙族3《黑月之潮》11个分卷、龙族4《奥丁之渊》3个分卷。

## 四卷演进

- **龙族1**：以普通少年的羞耻和被选择进入学院；校园游戏逐层转为真实战争；青铜城和康斯坦丁把屠龙还原为牺牲与兄弟悲剧。
- **龙族2**：从任务扩展到父亲创伤、血统临界、尼伯龙根和学院政治；权力、记忆、媒体与血液都成为战争工具。
- **龙族3**：把故事扩大到黑天鹅港、日本分部、白王圣骸、家族实验、东京灾难；私人旅行与国家级弑神行动并行。
- **龙族4**：把“寻找龙”转为“寻找被现实抹掉的人”；梦境、记忆、命运、尼伯龙根和父辈线相互嵌套，现实可靠性本身成为谜团。

## 最稳定的创作公式

现代生活缺口 -> 异常邀请/事故 -> 组织制度 -> 地下或异空间 -> 规则与代价 -> 身份/关系反转 -> 局部胜利与不可逆损失 -> 低强度余波 -> 更高层谜团。

## 关键差异化

不要把“江南感”简化成伤感、金句或网络梗。核心在于：

- 人物先以不体面的生活方式存在，再被迫面对神话。
- 大设定必须改变人物关系，而不只是增加百科信息。
- 喜剧是人物防御机制，悲剧是防御机制失效后的真实选择。
- 强者也被家庭、组织、记忆和血统代价困住。
- 反派的恐怖来自其逻辑完整，主人公的反抗来自关系而非纯粹正义。

## 自我进化记录

### 第 0 轮：规则初稿

- 优点：覆盖四卷世界观演进、人物声纹、场景节奏、谜团结构和连续性风险。
- 待测：是否能在短篇中同时保留日常质感、现代语感、规则战斗和情感余波；是否会过度依赖原作角色模板。
- 下一步：使用全新地点、原创配角和原创事件创作测试片段，再依据贴合度与原创度修订规则。

### 第 1 轮：测试完成

- 测试题目：《雨停以前》；全新人物、地点和事件。
- 自评：7.5/10。
- 发现：记忆抹除母题与龙族4过近，机构约束不足，配角动机不足，结尾代价不够具体。
- 已执行修订：将上述四项加入 SKILL 的后续创作约束，并保留“高层技法迁移、不复制原文”的边界。
