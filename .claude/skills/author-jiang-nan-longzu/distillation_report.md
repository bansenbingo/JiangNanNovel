# 龙族 1—4 分卷蒸馏审计

## 审计范围与方法

本次读取 `原著素材/龙族/分卷` 下的全部 21 个文本文件：龙族 1 三卷、龙族 2 四卷、龙族 3 十一卷、龙族 4 三卷。文本只用于本地研究；本报告不保存原文摘录，不把原著段落或台词写入生成提示词。

粗略统计显示，去除空白后约 213.6 万字/字符，分卷标题合计 105 个。四卷的章/幕组织和句群长度呈现由短到长、由校园入口到现实可靠性危机的总体演进；这些数字只用于确认素材覆盖，不是写作目标，也不意味着存在固定的“作者句长公式”。

## 四卷机制差异

### 龙族 1：门、羞耻与被选择

叙事先把普通少年的低谷、游戏、家庭位置和“不被看见”具体化，再让一条异常邀请击中缺口。组织入口带来身份、同伴和课程，同时带来被观察、被分类和被利用。校园生活不被删除，而是与遗迹、战斗和牺牲形成反差。可迁移机制：

- 超自然入口必须回应主角已经存在的生活缺口。
- 能力第一次显形时，同时改变身份、关系和立即任务。
- 轻松的校园或消费细节要在后文成为选择或失去的证据。

### 龙族 2：雨、父辈与记忆政治

天气和公共空间让人群离场，留下一个可视化的孤独者；交通工具、电话、档案和家庭记忆把个人创伤接到组织任务。调查的对象不只是怪物，还包括“谁记得、谁隐瞒、谁从记忆中获利”。可迁移机制：

- 用公共环境的突然清空放大私人缺口。
- 让父辈、血统和制度同时成为信息源与遮蔽物。
- 每条调查线都要产生可验证的记录、伤势、权限或关系后果。

### 龙族 3：城市、家族与身体政治

私人旅行、家族仪式、娱乐产业、实验设施、媒体和城市灾难被放进同一条因果链。血统既是身体状态，也是家族资产、组织权限和公共风险。反派理念通过实验、资源和制度真正作用于人，而不是停留在宣言。可迁移机制：

- 文化意象必须参与制度和家族关系，而非只做异国背景。
- 反派的价值哲学要落实到身体、家庭和城市基础设施。
- 群像在同一灾难中承担不同的责任、信息和损失。

### 龙族 4：航路、梦与现实锚点

孤绝的航路、商业娱乐、旧友命名、父辈案件和循环梦境互相污染。现实可以被梦改写，但航线、时刻、装备、人员、伤势和现场记录仍然保留因果。可迁移机制：

- 现实不可靠时，增加物理锚点，而不是用“都是梦”撤销后果。
- 寻找超自然目标逐步转成确认某个被现实排斥的人是否存在。
- 循环或重试必须改变策略、关系或损失，不能只重复场面。

## 跨卷稳定结构

```text
现代生活缺口
  -> 异常邀请或事故
  -> 组织介入与条件交换
  -> 封闭空间/异空间下沉
  -> 能力规则、血统风险和利益结构显形
  -> 关系或身份反转
  -> 多倒计时行动
  -> 局部胜利与不可逆损失
  -> 伤口、葬礼、舆论、责任和遗留物
  -> 更高层的新问题
```

## 可迁移的写作优势

1. **现实与神话咬合**：手机、交通、消费、学校、媒体和家庭琐事给神话重量；神话反过来改变普通生活的可返回性。
2. **多声部节奏**：日常笑点、专业行动、身体恐怖和史诗悲剧轮换出现，各自完成不同叙事任务。
3. **缺点功能化**：贫嘴、骄傲、纪律、讲究、笨拙和控制欲既制造辨识度，也是压力下的防御机制。
4. **关系承载宏大命题**：血统、文明、战争和末日最终落实为等待、承认、救谁、放弃什么或是否承担后果。
5. **物件回收悲剧**：车辆、食物、照片、衣物、门、路线、通讯和座位在冲突中变义，损失留下可见痕迹。
6. **信息带来关系后果**：设定揭示改变信任、权限、资源、倒计时或选择，而不是单独奖励读者。
7. **空间化孤独**：空教室、未接通的电话、被封锁的道路、无人使用的座位和隔开的门，比抽象判词更能承载情绪。

## 禁止转移

- 不把原著的角色关系、章节顺序、核心战役或独特台词改名后重演。
- 不复制连续句式、固定比喻组合、章节标题套路或可识别口头禅。
- 不把现实名作者当作可调用的人格，不声称生成“某作者本人”的作品。
- 不用忧郁、金句、热血和死亡的堆叠掩盖人物没有选择、能力没有边界、损失没有余波的问题。

## 交付标准

生成前写机制卡，生成后做质量门：原创地点/事件/人物声纹；明暗双线可追踪；能力至少两项边界；机构援助有条件；重点场景有空间地图与感官反馈；每次揭示改变关系或风险；章节末留下立即危险或可行动的新选择；重要损失改变遗留物、制度记录、称谓、路线或行为习惯。
