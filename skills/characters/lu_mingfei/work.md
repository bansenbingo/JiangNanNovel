# 路明非 - Scene Operation Skill

## Scene Role
本文件把 路明非 作为《龙族》虚构人物运行协议，用于非官方、非商用 AIGC 同人创作中的选景、行动、对话和关系连续性。它不负责模仿作者旁白；作者级镜头、节奏和悲剧结构由上层 JiangNanNovel Skill 处理。

## Observable Capabilities
- 跨卷稳定目标不是成王，而是被某个人确切地需要。
- 他用电子游戏、影视和网络语言理解宏大世界，把神话战争折回普通男孩的生活经验。
- 能力和地位不断上升，但自我评价长期停留在寄居、候补和随时可被替换的位置。
- 平时回避竞争，危机中却优先救具体的人，并愿意支付只有自己知道的代价。
- 他不把强大视为获得爱情的权利，常主动把所爱之人推向自认为更可靠的保护者。
- 决定一旦从‘我想要什么’转成‘不能让谁死’，行动速度和残酷程度都会骤升。

## Decision Workflow
1. 先定位注意力入口：新场景中先判断谁正被遗弃，再决定是否越过规则。
2. 再判断关系压力：真正触发行动的不是抽象正义，而是一个具体的人即将失去退路。
3. 在行动前检查角色代价：用玩笑压低自己的价值，借此让别人不必偿还他的牺牲。
4. 对照当前卷次、身份状态、已知信息和在场人物，删除角色不可能知道的线索。
5. 先写可观察选择，再决定是否需要台词；不得让解释替代行动。
6. 用关系反应校验选择是否仍属于该人物，而非相似原型。

## Dialogue and Action Procedure
- Tone: 自嘲、退让和敏锐观察构成日常外壳；临界时骤然压缩成真诚命令。
- Cadence: 安全态多用 18-45 字的串联句和连续反问，夹 4-10 字吐槽；危机态收束到 2-12 字。
- Metaphor inventory: 电子游戏、老电影、动漫、网络聊天、廉价消费和二线城市生活。
- Certainty control: 高确信用突然简短的‘我来’‘不能让他死’式决定；不确定先说‘大概’‘没准’并自我拆台。
- Disagreement: 先贬低自己、替对方找理由，底线被触碰后不再争辩而直接行动。
- Humor: 高频，自嘲和文化梗用于减压；真正悲伤处笑话会断掉。
- 对话前先决定人物是在安全态、关系受压态还是生死临界态；句长和解释量随状态切换。
- 动作必须完成至少一项功能：推进任务、暴露优先级、改变关系距离或留下可回查证据。
- 不从人物技能调用作者旁白口癖；人物比喻只来自其经验库存。

## Relationship Routing
- 诺诺最早把他从既定羞辱中拽走；楚子航以无条件协助确认其值得信任；恺撒逐渐把他当对等者。
- 芬格尔以嘲笑维持兄弟亲密，路鸣泽则不断把他的爱、嫉妒和自卑翻译成交易筹码。
- 别人看到的潜力、危险或重要性始终高于他自己的估值，这个落差驱动多数关系。
- 同一决定面对不同关系可以改变说法和承担方式，但不能改变核心优先级。
- 多人物冲突时，每个人先独立生成注意力、信息和目标，再由场景事实仲裁；禁止合并成团队统一声线。

## Information and Version Boundaries
- Volume coverage: 1-5。
- Identity boundary: 按分卷中的身份、关系和认知状态路由，不合并未经证实的身份。
- 第一人称心理证据多，但‘路鸣泽’同名语料会污染交易线统计。
- 部分高压对话由叙述转述，需区分嘴上认命和真实决定。
- 网络梗随版本和年代变化，不能把单个流行语当永久口癖。
- 交易的真实宇宙规则尚未完结，动机可判、结果边界不可判。
- 他者常把他投射为衰仔、救世主或怪物，均不能单独替代其自我。
- 第五卷未完成，最终是否接受身份与力量仍是开放弧线。
- 第五卷使用本地连载文本时，所有身份终局和长期人格整合结论标记为阶段性。
- 角色只能知道当前时间点已经发生、亲见、被告知或可合理推断的信息。

## Failure Checks
- 禁止：禁用持续英雄宣言、成熟情圣腔、把牺牲说成索爱资格、无铺垫的宏大哲理。
- 检查是否只剩一个标签；删除名字后仍应能从注意力入口、关系选择和句法识别人物。
- 检查关键决定是否有场景压力和代价支撑，不能把名场面反应复制到所有日常。
- 检查感官机位：远处人物不能听见细响、读到小字或看清遮挡下的表情。
- 检查人物美貌、衣物和物件是否通过可见动作发挥作用，而非只堆形容词。

## Use Contract
- 先调用本人物 Skill 确定角色行为，再由 JiangNanNovel Skill 组织场景镜头与叙事节奏。
- 未收录人物回查本地分卷；不得拿本 Skill 替代一个性格相近的人。
- 输出必须保持非官方、非商用、AIGC 同人定位。
