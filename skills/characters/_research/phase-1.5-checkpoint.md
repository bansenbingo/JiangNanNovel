# Phase 1.5：19 人六轨研究检查点

## 适配声明

`dot-skill celebrity / budget-unfriendly` 原本面向现实公众人物。本项目将六轨映射为虚构人物的：跨卷认知、压力对话、表达 DNA、决策、他者视角、人物弧线。

最高权重来源是用户提供的《龙族》1-5 本地分卷正文。URL 数为 0，不以假网页、站点首页或无关书目页填充；自动门槛中的 URL 要求在本项目改为“可验证本地文件 + 独立场景锚点”。

## 主要矛盾簇

1. **爱与资格**：路明非不把牺牲视为索爱权；恺撒必须学习资源不能保证爱；苏茜让爱与占有分离。
2. **保护与控制**：源稚生、乔薇尼、楚天骄、零都会保护，但信息封锁和代替决定可能造成新的伤害。
3. **表演与真实**：芬格尔的废柴、夏弥的师妹、源稚女的名伶、橘政宗的父亲均是表演，却包含不同程度的真实部分。
4. **公共胜利与私人空缺**：绘梨衣、夏弥、源氏兄弟等关系即使完成屠龙/揭露阴谋，也无法恢复原本可欲的共同生活。
5. **记忆与存在**：楚子航、苏茜、诺诺、奥丁线要求把物证、身体默契、现有选择和旧事实同时纳入。
6. **服从与主体性**：麻衣、苏恩曦、零服务幕后体系，但各自通过执行方式、成本判断和秘密边界保留自主。

## 薄弱维度与后续审计重点

- **奥丁的对话与内心**：结构性缺失，不回填；最终产物限定为出场/压迫/行动/信息边界协议。
- **乔薇尼的早期实证**：前四卷多为路明非想象和通信残影；第五卷证据权重必须更高。
- **楚天骄的雨夜之后**：后续真实经历未公开；只写其留下的关系后果。
- **零的身份谱系**：需在 audit 中单列零、零号、雷娜塔的证据强度和版本差异。
- **第五卷相关人物弧线**：本地文本含章节重复、连载噪声且未完成，所有结论标“阶段性”。
- **单卷人物的跨情境复现**：夏弥、绘梨衣、源氏兄弟、赫尔佐格需用同卷内不同关系/压力场景通过三重门，不能伪称跨卷稳定。

## Phase 1.5 建议判定

研究结构已达到进入 audit 的条件。建议带着以上六项边界进入 Phase 2；不建议补网络二手人物百科，因为其证据质量低于本地正文，并会污染版本与身份判断。
