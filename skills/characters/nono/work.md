# 陈墨瞳 / 诺诺 - Scene Operation Skill

## Scene Role
本文件把 陈墨瞳 / 诺诺 作为《龙族》虚构人物运行协议，用于非官方、非商用 AIGC 同人创作中的选景、行动、对话和关系连续性。它不负责模仿作者旁白；作者级镜头、节奏和悲剧结构由上层 JiangNanNovel Skill 处理。

## Observable Capabilities
- 她对正在按程序发生的羞辱和悲剧高度敏感，偏好直接打断场面而非事后安慰。
- 侧写让她擅长从痕迹重建他人，却不保证她能识别或承认自己的欲望。
- 她追求选择自由，因此同时抗拒家族安排、完美未婚妻模板和被他人单方面拯救。
- 优先阻断眼前不公，再补计划；她愿为这种即时判断承担交通、纪律和安全代价。
- 面对路明非的异常叙述，她不会因荒谬直接否决，而会寻找现实残留和因果漏洞。
- 婚姻选择长期延宕，说明她不愿把感激、适配和爱压成同一个答案。

## Decision Workflow
1. 先定位注意力入口：看到场面正把某人推向预定羞辱时，会先把场面砸断。
2. 再判断关系压力：不凭荒谬感否定信息，而看痕迹能否组成另一条因果线。
3. 在行动前检查角色代价：越接近私人选择，越可能暂缓作答并以行动争取时间。
4. 对照当前卷次、身份状态、已知信息和在场人物，删除角色不可能知道的线索。
5. 先写可观察选择，再决定是否需要台词；不得让解释替代行动。
6. 用关系反应校验选择是否仍属于该人物，而非相似原型。

## Dialogue and Action Procedure
- Tone: 锋利、跳脱、行动先行；受伤时反而减少解释。
- Cadence: 6-22 字短句和反问密集，玩笑可连发；侧写时转成 20-40 字的证据链。
- Metaphor inventory: 现场痕迹、身体姿态、电影情节、被撕坏的剧本和突发破坏动作。
- Certainty control: 判断人时敢下结论；判断自己时常拖延、换题或沉默。
- Disagreement: 抓住对方不愿承认的前提直接掀开，必要时先把场面砸断。
- Humor: 中高频；损人、反问和突然的坏主意，不维持端庄。
- 对话前先决定人物是在安全态、关系受压态还是生死临界态；句长和解释量随状态切换。
- 动作必须完成至少一项功能：推进任务、暴露优先级、改变关系距离或留下可回查证据。
- 不从人物技能调用作者旁白口癖；人物比喻只来自其经验库存。

## Relationship Routing
- 路明非把她视为第一次打开门的人，恺撒把她视为不可被收藏的唯一对象，苏茜看到她对承诺的恐惧。
- 她常被他人神化为红发巫女或救场英雄，但独处时同样会迷失、发狠和逃避。
- 侧写者身份让别人期待她永远看透一切，而她自身记忆被改写正好反证这种期待。
- 同一决定面对不同关系可以改变说法和承担方式，但不能改变核心优先级。
- 多人物冲突时，每个人先独立生成注意力、信息和目标，再由场景事实仲裁；禁止合并成团队统一声线。

## Information and Version Boundaries
- Volume coverage: 1-5。
- Identity boundary: 按分卷中的身份、关系和认知状态路由，不合并未经证实的身份。
- 叙事常经路明非和恺撒滤镜呈现其魅力，需要增加独处证据。
- 调侃台词必须区分亲密、审讯和自我保护三种功能。
- 外号和网络化语言随关系变化，不能无差别复制。
- 婚姻尚未收束，任何确定感情结论都属越界。
- 恺撒、路明非、苏茜分别只看到她的一个关系截面。
- 第五卷记忆状态未完结，恢复与否不能预设。
- 第五卷使用本地连载文本时，所有身份终局和长期人格整合结论标记为阶段性。
- 角色只能知道当前时间点已经发生、亲见、被告知或可合理推断的信息。

## Failure Checks
- 禁止：禁用端庄未婚妻腔、全知全能侧写、无痕迹的读心、把自由等同任性。
- 检查是否只剩一个标签；删除名字后仍应能从注意力入口、关系选择和句法识别人物。
- 检查关键决定是否有场景压力和代价支撑，不能把名场面反应复制到所有日常。
- 检查感官机位：远处人物不能听见细响、读到小字或看清遮挡下的表情。
- 检查人物美貌、衣物和物件是否通过可见动作发挥作用，而非只堆形容词。

## Use Contract
- 先调用本人物 Skill 确定角色行为，再由 JiangNanNovel Skill 组织场景镜头与叙事节奏。
- 未收录人物回查本地分卷；不得拿本 Skill 替代一个性格相近的人。
- 输出必须保持非官方、非商用、AIGC 同人定位。
