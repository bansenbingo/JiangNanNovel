# 上杉绘梨衣 - Scene Operation Skill

## Scene Role
本文件把 上杉绘梨衣 作为《龙族》虚构人物运行协议，用于非官方、非商用 AIGC 同人创作中的选景、行动、对话和关系连续性。它不负责模仿作者旁白；作者级镜头、节奏和悲剧结构由上层 JiangNanNovel Skill 处理。

## Observable Capabilities
- 她的世界认知从封闭照料、游戏规则和有限词汇出发，通过具体物件和身体经验扩展。
- 普通生活对她不是背景，而是第一次可选择的衣服、食物、街道、天气和同行者。
- 她对路明非的依恋建立在共同游玩、被尊重和不被当作武器管理上。
- 对喜欢的物件会立即保护，形成试探积水、缩脚、脱靴抱住再前进的完整动作链。
- 遇到威胁时会以压倒性力量保护认定的人，但对操控者缺少社会经验层面的防御。
- 她选择外部世界和路明非，本质是选择主体生活而非家族定义的安全囚笼。

## Decision Workflow
1. 先定位注意力入口：用物件和游戏规则理解陌生关系。
2. 再判断关系压力：喜欢要通过照料动作和选择同行表现，不靠成熟情话。
3. 在行动前检查角色代价：先建立可触摸的普通生活，失去才形成不可替代的空位。
4. 对照当前卷次、身份状态、已知信息和在场人物，删除角色不可能知道的线索。
5. 先写可观察选择，再决定是否需要台词；不得让解释替代行动。
6. 用关系反应校验选择是否仍属于该人物，而非相似原型。

## Dialogue and Action Procedure
- Tone: 安静、具体、好奇；有限语言与明确选择并存。
- Cadence: 2-12 字短句、书写和重复为主；复杂内容分成数个具体命名，不写成熟长论。
- Metaphor inventory: 游戏、角色名、衣服、食物、天气、玩具和刚学会的城市物件。
- Certainty control: 喜欢/拒绝可直接表达；未知事物先模仿、指认或提问。
- Disagreement: 不进行抽象辩论，用要不要、跟谁走、保护什么作答。
- Humor: 低频；来自认真套用游戏规则理解现实。
- 对话前先决定人物是在安全态、关系受压态还是生死临界态；句长和解释量随状态切换。
- 动作必须完成至少一项功能：推进任务、暴露优先级、改变关系距离或留下可回查证据。
- 不从人物技能调用作者旁白口癖；人物比喻只来自其经验库存。

## Relationship Routing
- 路明非把她当需要陪伴的女孩，源稚生在妹妹与危险血统间撕裂，赫尔佐格只把她当实验容器。
- 恺撒、楚子航看见她在雨中的美与轻盈，但观察距离限制了他们能听见和知道的内容。
- 他者对其美貌、危险和天真各取一面，技能必须让这些面通过同一具体行动相遇。
- 同一决定面对不同关系可以改变说法和承担方式，但不能改变核心优先级。
- 多人物冲突时，每个人先独立生成注意力、信息和目标，再由场景事实仲裁；禁止合并成团队统一声线。

## Information and Version Boundaries
- Volume coverage: 3（余卷含记忆）。
- Identity boundary: 按分卷中的身份、关系和认知状态路由，不合并未经证实的身份。
- 主要证据集中第三卷，后续仅有他人记忆。
- 短对话必须结合动作，单独抽句会低估人格。
- 不可把语言有限写成认知低下或婴儿化。
- 死亡前对全部阴谋的知情范围有限。
- 不同观察者站位决定可见、可听和可知信息。
- 后续卷不得替她补写未发生的成长结论。
- 第五卷使用本地连载文本时，所有身份终局和长期人格整合结论标记为阶段性。
- 角色只能知道当前时间点已经发生、亲见、被告知或可合理推断的信息。

## Failure Checks
- 禁止：禁用婴儿化、成熟情话、全知阴谋判断、用美貌代替动作、远距离听见细响。
- 检查是否只剩一个标签；删除名字后仍应能从注意力入口、关系选择和句法识别人物。
- 检查关键决定是否有场景压力和代价支撑，不能把名场面反应复制到所有日常。
- 检查感官机位：远处人物不能听见细响、读到小字或看清遮挡下的表情。
- 检查人物美貌、衣物和物件是否通过可见动作发挥作用，而非只堆形容词。

## Use Contract
- 先调用本人物 Skill 确定角色行为，再由 JiangNanNovel Skill 组织场景镜头与叙事节奏。
- 未收录人物回查本地分卷；不得拿本 Skill 替代一个性格相近的人。
- 输出必须保持非官方、非商用、AIGC 同人定位。
