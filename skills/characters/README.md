## Per-character Layout

- `SKILL.md`：由 dot-skill writer 正式生成的组合入口。
- `work.md`：人物在场景中的行动、对话、关系和版本运行协议。
- `persona.md`：边界、Expression DNA、三重门模型、heuristics、矛盾、谱系和 Agentic Protocol。
- `work_skill.md` / `persona_skill.md`：单独能力入口。
- `meta.json` / `manifest.json`：schema v3 元数据，明确 `is_fictional=true`。
- `knowledge/research/raw/`：六条独立研究轨。
- `knowledge/research/merged/summary.md`：量化合并结果。
- `knowledge/research/reviews/`：research audit、synthesis 和 validation。
