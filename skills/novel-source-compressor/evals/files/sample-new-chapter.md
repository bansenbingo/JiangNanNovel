# 第五章 井下的站台

沈砚没有跳进井里，而是沿着检修梯下到一座倒置的站台。父亲坐在长椅上，外表没有变老，却说自己已经等了十七年。井下的列车每到一班就会带走一个镇民的名字，灯塔靠这些名字维持镇子的“白天”。父亲要求沈砚把怀表放回车头，这样灯塔会忘记沈砚和阿梨；沈砚拒绝，因为阿梨的姐姐还在车上。

陆川从上面追下来，承认镇长知道真相，并且准备让整座镇子迁入井下。沈砚发现怀表并不是钥匙，而是记录被带走名字的账本。列车进站时，他撬开车门，让阿梨的姐姐跳下车，但账本缺了一页。父亲把缺页藏在自己胸口，列车带走了他。沈砚和三姐妹回到地面，发现镇上的人开始忘记“北线”这个词。章节末尾，周姨寄来第二只空信封。
