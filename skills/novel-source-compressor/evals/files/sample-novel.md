# 第一章 旧车站

沈砚在凌晨收到父亲寄来的空信封，封口压着一枚铜色车票。父亲三年前在北线失踪，警方认定为列车事故，但沈砚知道父亲从不坐夜车。车票背面写着“不要把灯带进隧道”。他没有报警，而是去找修表的邻居周姨，问父亲是否留下过一只停在十一点十七分的怀表。周姨承认怀表在她手里，却要求沈砚先答应不去北线。

# 第二章 灯塔镇

沈砚带着怀表乘上北线旧车。车上只有售票员陆川和一个自称来拍照的女孩阿梨。怀表在进入隧道前突然走动，陆川要求所有人熄灯。阿梨没有照做，她说隧道里有一座从地图上消失的灯塔。车厢停在黑暗中，沈砚听见父亲的口哨声，从车尾传来。陆川承认自己每月都把一名乘客送到灯塔镇，但这次车票上多了沈砚的名字。

# 第三章 灯塔镇的规则

三人抵达没有白天的灯塔镇。镇民不许说出失踪者的全名，不许打开面向北方的窗，也不许让灯火照到井里。陆川想把怀表交给镇长换取离开的车票；阿梨却发现怀表的指针指向井底。沈砚在父亲的旧屋找到一张未寄出的信，信中写道：灯塔不是引路，它在替某个东西记住每一班车。沈砚烧掉信的一角，留下“第十七班”四个字。

# 第四章 没有返程的车

镇长宣布下一班车只带两个人离开。陆川承认当年父亲曾让他把怀表送回井底，自己因为害怕而把它藏在周姨那里。阿梨告诉沈砚，她来灯塔镇不是拍照，而是寻找失踪的姐姐，姐姐的名字已经从镇民记忆里消失。沈砚可以带着阿梨离开，也可以留下找父亲。夜里井中传来列车声，怀表停在十一点十七分。沈砚把唯一的返程票塞给阿梨，自己提灯走向井边。原文在此中断。
