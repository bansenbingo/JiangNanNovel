# High-Leverage Question Bank

每轮从下表挑 1-3 个，不要按顺序全问。选择标准是“答案不同会不会改变主线、结局或篇幅”。对人物内核、关系、情绪和结局等高杠杆变量，先问开放问题，再给选项支架；只有表层或用户已明确的变量才可直接让用户选。

| 变量 | 什么时候问 | 选项示例 | 不问的默认 |
| --- | --- | --- | --- |
| mode | 用户同时说续写和重写 | 接原文 / 从分歧点重走 / 只借人物关系 / 全新原创化 | 以用户明确的动词为主 |
| endpoint | 有起点但没有收口 | 完成任务 / 保住关系 / 真相曝光 / 留开放结局 | 先锁一个可完成的阶段结局 |
| canon | 既有 IP 或旧稿与新想法冲突 | 严格连续 / 有限改动 / 平行线 | 保留已给事实，把未给处标推演 |
| preserve_change | 用户说“改写”但范围模糊 | 保留人物 / 保留世界 / 保留主题 / 只保留核心场面 | 保留核心人物与主题，重做因果 |
| center | 人物很多、主线发散 | 单一视角 / 双核心 / 群像但一条主问题 | 选择最能承受代价的核心人物 |
| scale | 未说明长度 | 单章 / 3-5 章 / 一卷 / 全书 | 先交付可验证的小版本 |
| tone | 参考作品或情绪描述模糊 | 轻快外壳 / 压迫悬疑 / 温柔余味 / 冷峻悲剧 | 保持材料既有温度，避免擅自加重 |
| rating_boundary | 涉及暴力、性、未成年人或自伤 | 可写到什么程度、哪些必须淡出 | 采用克制的非图像化处理 |
| reveal | 用户想要反转但未说明信息分配 | 读者先知 / 角色先知 / 同步揭晓 | 让读者和视角人物各保留一层未知 |
| ending_pressure | 结局只说“震撼” | 公共胜利 / 私人空缺 / 关系保住但目标失败 / 双重代价 | 让胜利不能抹平私人损失 |
| style_reference | 用户说“像某作” | 借节奏 / 借结构 / 借意象功能 / 仅作情绪参照 | 只提取高层机制，不复制表达 |

## 开放问题模板

| 方向 | 开放邀请 | 可选支架的作用 |
| --- | --- | --- |
| 画面 | “你最想保留的一个瞬间、空间或动作是什么？” | 帮用户定位发生在开端/中段/结尾，不能替用户规定内容 |
| 关系 | “你希望这两个人最后以什么状态面对彼此？” | 提供相守、错过、互相原谅、无法再见等方向，但允许完全不同的回答 |
| 情绪 | “读者合上这一卷时，你希望胸口留下什么感觉？” | 用温暖、刺痛、释然、余悸等词帮助启动，不把情绪锁成喜悲二选一 |
| 代价 | “哪一种损失不能被胜利轻易抹平？” | 提醒公共结果/私人结果双结算 |
| 边界 | “哪些事实、人物、意象或结局即使大纲更方便也不能动？” | 将自由回答登记为 locked facts 或 hard boundaries |

## 推荐提问句式

```text
我先锁定了 X、Y、Z。先不用选：你脑海里的结尾画面/两人关系/读者情绪是什么？可以用几句话、一个场景或一个比喻描述。
如果你想快速定位，可以参考 A/B/C；它们只是支架，也可以给出完全不同的版本。
这个问题会改变第三段的压力和结局回收。我会先复述你的意思，再把它写入 vision_capture；你暂时不答时，我采用推荐默认并标为可回滚假设。
```

## 不该提问的内容

- 已经在原文或用户前文明确写出的事实。
- 可以由低风险默认处理的字体、标题、命名等表层选择。
- 只为显得专业的世界观百科问题。
- 不影响故事路线的偏好，在主线没有锁定前连续追问细节。
- 用 A/B/C 逼用户替自己的复杂构思选一个标签。
- 把用户的比喻、片段画面或矛盾愿望擅自翻译成确定事实。
