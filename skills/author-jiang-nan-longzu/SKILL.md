# 龙族原创化写作模型

本 skill 将龙族 1-4 的公开世界观锚点、分卷演进和两篇研究论文中的类型分析，转化为可迁移的创作约束。它不是“复制作者文风”的模型，也不应输出原著连续情节、独特台词或可识别的原文段落。

详细规则见同目录的 `author_persona.md`、`writing.md` 和 `writer_profile.md`。其中 `writer_profile.md` 是可直接注入系统提示词的作家配置，`distillation_report.md` 记录了对 21 个分卷的高层蒸馏结果；所有内容都经过原创化与版权边界修订。

## 工作流程

1. 先确认时间点、地点、已知伤亡、人物关系、信息权限和本章主问题。
2. 为主角写出表层目标、隐性渴望、核心恐惧和不能承认的代价。
3. 用一个具体的现代日常入口承载异常，让异常通过物件、制度、天气、网络或关系缝隙侵入。
4. 拆出明线目标、暗线目标、倒计时、规则限制、失败代价和章末新问题。
5. 每次设定揭示至少改变一项关系、选择或风险；禁止百科式解释。
6. 完成后检查原创性、人物声纹、能力边界、因果闭环、情绪余波和连续性。
7. 最后进行“赏析维度检查”：青春成长是否具体化，孤独是否由空间和行动呈现，现实锚点是否承载神话，伏笔是否能重读增值。
8. 进行“文笔优势转译检查”：确认画面、口语、节奏、情绪和伏笔都服务于人物选择；只迁移可解释的方法，不追求句式、口头禅或可识别腔调。

调用作家配置时，先读取 `writer_profile.md` 的“角色协议、核心风格向量、情节引擎和质量门”，再按用户指定的输出模式生成；需要了解四卷差异时，读取 `distillation_report.md`，不要重新载入原著正文。

## 可迁移的核心气质

- 现代校园、都市消费、网络文化和家庭琐事，与遗迹、屠龙战争和末日神话并置。
- 语气在青春喜剧、黑色幽默、专业行动、身体恐怖和史诗悲剧之间有节奏地切换。
- 庄严场景落到具体物件，紧张场景保留人物习惯；玩笑缓冲压力，但不撤销死亡后果。
- 关注被看见、被选择、被记得、被需要，并把这些愿望放进血统、组织和命运的高压系统。
- 英雄性来自选择并承担关系后果，而不是单纯升级。
- 龙族题材的文学张力来自“普通生活的可返回性”逐步消失；每次进入神话世界，都应让角色失去一项原本以为可以保留的普通东西。

## 世界观底盘

- 龙是拥有文明、语言、历史和权力结构的高等生命，不是只负责被击杀的怪物。
- 混血种获得能力，也承担血统污染、失控、死侍化和身份异化风险。血统浓度同时是能力、社会等级、政治资产和身体风险。
- 言灵是改变局部规则的能力。每种高阶能力至少设置两项边界：范围、媒介、稳定性、准备时间、反制条件或使用代价。
- 强化必须同时写收益和损伤：可能损失寿命、自我、证据可信度、装备或组织信任。
- 炼金术把能力制度化为武器、矩阵、权限和组织资源；战斗先呈现空间、声音、温度、材质和物理反馈，再解释机制。
- 隐秘组织同时是学校、军队、研究机构、情报中心和文明避难所。机构的援助应附带权限、政治条件或资源交换。
- 异空间依附现实地点、创伤记忆、道路、建筑、镜面、水面或特定时间；必须有入口、路线、时间和失败规则。

## 人物工程

人物不要直接套用原作角色模板。可以借鉴“防御外壳与隐性渴望”的设计方法：

- 先写角色在日常中的不体面状态，再写他被迫面对神话时失去的借口。
- 配角必须有自己的欲望、隐瞒和损失，不能只负责解释设定。
- 反派要有稳定、自洽的价值哲学，例如进化、秩序、复仇、记忆或控制；恐怖来自逻辑完整，不来自咆哮。
- 亲情、友情和爱情不是自动治愈创伤的工具，而是人物选择承担创伤后果的理由。

## 情节结构

推荐的原创单卷链条：

`现代生活缺口 -> 异常邀请或事故 -> 组织介入 -> 空间下沉 -> 规则与代价显形 -> 关系反转 -> 高危行动 -> 局部胜利与不可逆损失 -> 低强度余波 -> 更高层问题`

每个场景至少具备外部目标、人物私心、空间障碍、能力规则和关系变化。高危任务配置三种倒计时；失败至少造成死亡、身份暴露、关系破裂、资源耗尽、舆论反噬或规则升级中的一项。战斗之后写处理伤口、葬礼、舆论、责任和记忆残留。

谜团采用“政治解释 -> 科学解释 -> 神话解释”的递进，但每次只解决一层。反转要改写过去事件的意义，不能抹掉角色此前行为的合理性。

## 赏析转写层

网络文学赏析常从青春成长、孤独与身份认同、现实都市和神话世界的咬合、东方神话的现代转换、日常细节制造悲剧反差等角度理解《龙族》。这些内容只作为高层检查维度：不能把评论原句当小说语言，不能把读者的单一解读当成唯一事实，也不能用“忧郁、金句、死亡”三个标签代替人物和因果。

创作时要求：

- 青春成长必须由一次具体选择证明。
- 孤独必须落到电话、座位、门、照片、食物、路线或未完成的动作。
- 神话必须通过组织、家族、城市、技术或公共事件进入现实。
- 文化意象必须参与权力和关系，不做背景贴纸。
- 轻松日常必须有独立戏剧功能，并在后续因果中回响。
- 悲剧必须改变遗留物、制度记录、人物习惯或关系称呼中的至少一项。

## 文字层面的高层规则

- 环境铺陈使用温度、声音、材质、光线和方向；危险启动后缩短句子，增加动词、数字、设备反馈和选择压力。
- 情感高潮少解释，多写动作、停顿、物件和称谓变化。
- 说明嵌入误解、专业流程、争论或现场后果，不写成设定手册。
- 每篇只选少数主意象反复变义，例如门、列车、雨、水、火、照片、食物或车辆；不要堆砌符号。
- 幽默必须来自人物防御机制，悲剧来自防御机制失效后的选择；不要用金句和网络梗代替情节。

## 文笔优势的原创化学习

以下不是对现实作者的身份判断，也不是可复制的“江南腔”。它们是从公开读者赏析中提炼出的可验证写作机制：

- **画面先行，情绪后置**：先用一个可拍摄的动作、物件、光线或空间关系让读者看见场面，再让情绪从人物的选择和反应中浮现；避免先替读者宣布“他很孤独”或“这一刻很悲壮”。
- **雅俗同场**：让有诗性或神话感的意象与欠费、迟到、食物、交通、社交尴尬等现代细节同场出现。两者必须互相改变意义，不能把日常当笑料、把神话当贴纸。
- **对白制造速度，叙述制造回响**：对白短、具体、有身份差异，常带误解、回避或防御；叙述在关键节点停下来，让一个动作或物件承担未说出口的关系信息。
- **节奏以声部切换而非音量堆高**：在轻松日常、调查悬疑、行动危机和情绪余波之间切换。每次切换都要改变信息量、风险或关系，不能只换形容词。
- **宏大命题落到私人选择**：血统、战争、文明和末日必须最终逼问一个人是否等待、承认、离开、救谁或承担什么。优势不在口号，而在抽象命题被具体代价验证。
- **悲剧依靠反差与回收**：先让角色拥有可信的轻松、习惯或小幸福，再让同一细节在后文因损失而变义。死亡或离别不能只靠宣告，应留下物件、称谓、路线、制度记录和行为习惯的变化。
- **人物魅力来自缺点的功能化**：贫嘴、骄傲、冷漠、讲究或笨拙既是笑点，也是防御机制；在压力下它们可以帮助人物行动，失效时则暴露真正的恐惧。
- **信息揭示带着关系后果**：设定不是奖励读者的百科知识。每次揭示至少改变信任、权限、选择、资源或倒计时中的一项，并保留一个尚未解释但可验证的问题。

### 信息编排与镜头语法

把场景当成一组有目的的视觉、听觉和心理信息来排列，而不是把所有细节同时堆给读者。默认使用“建立舞台 -> 锁定人物 -> 追踪关系 -> 放慢感官 -> 转入主观”的五步骨架，但可按场景目标删减或倒置：

1. **全景建立舞台**：先交代天气、光源、地面、距离、方向或人群状态，让后续动作有可验证的空间。
2. **中景锁定关系**：用人物进入、停下、遮挡、递交或保护等动作，明确谁主动、谁被照顾、谁被隔开。
3. **特写选择信息**：镜头沿一条清晰的视线或动作链移动，只挑一个能暴露性格、欲望或风险的局部，不平均描写身体和物件。
4. **跟拍或声画对位**：让人物在空间中移动，同时保留脚步、机械声、衣料、雨水、呼吸等声音；宏观运动与微观反馈要互相校准。
5. **主观镜头完成变义**：从可观察的事实切入角色感受。声音可以被屏蔽，距离可以被拉长，时间可以变慢，但主观变形必须由人物当下的欲望、记忆或关系触发，并留下现实后果。

镜头不是电影术语装饰。每次景别变化必须至少完成一项任务：提供空间信息、改变风险、暴露人物、推进关系或改变读者对某个物件的理解。镜头下移、推近、拉远、定格和慢动作都应有叙事理由；不要用连续特写替代人物选择。

- **空间先于抒情**：读者必须先知道人物在哪里、要去哪里、被什么阻挡，才进入诗性或心理化描述。
- **由大到小再回到心里**：常用“环境 -> 人物关系 -> 局部动作/物件 -> 感官细节 -> 主观感受”的收束路径，让情绪从画面中生成。
- **镜头链要有动词**：优先写停、跳、伸、缩、抱、跑、拎、撞、回头等改变位置或关系的动作，少用静态形容词连续排列。
- **声画不可分家**：视觉信息出现时，尽量配置一个相称的声音、触感或温度；声音不只是气氛，也可以提示人物距离、身体状态和危险方向。
- **慢镜头必须稀缺**：只有当某个瞬间对人物具有异常心理重量时才放慢；慢下来之后要让读者看见新的关系或感受信息，而非重复动作。
- **诗性必须回到人物**：比喻和抽象化感受要解释人物此刻看见世界的方式，不能成为作者脱离场面的独白。

### 学习算法

写作前用“机制卡”替代风格模仿：

1. 写出本场的现实入口、异常反馈、人物防御动作和不可逆代价。
2. 先画出五步镜头链：舞台全景、关系中景、关键特写、移动与声画、主观变义；注明每一步新增了什么信息。
3. 指定一个主意象，让它至少经历“生活物件 -> 冲突证据 -> 情感回响”三次变义。
4. 为每名主要角色写一条不同的口语习惯和一条回避方式；删掉所有角色都能说出的漂亮句子。
5. 用一段通俗对白推进任务，再用一个不解释的动作承接情绪；检查两者是否分别完成速度和余韵功能。
6. 危险段落逐步缩短句子、增加动词和可计数信息；余波段落恢复呼吸，但必须处理伤口、责任或关系变化。
7. 完成后反向检查：若删去比喻、金句或设定名词，人物是否仍在做选择？若不能，说明文学装饰没有转化为叙事功能。

### 明确不学习的内容

- 不复制原著句子、固定比喻、独特台词、章节标题套路或连续情节。
- 不把“忧郁、热血、金句、死亡”当作风格按钮，不用空泛哲思替代场面因果。
- 不把读者评论中的单一判断写成作者本人意图，不把无法核验的网页内容标记为事实。
- 不让所有角色共享同一种冷淡、漂亮或自嘲的说话方式；优先建立本工程的原创声纹。

## 章节标题与镜头

- 章节标题优先从本章真正改变意义的角色、双意象、动作、空间、宣言或极简词中选择。
- 标题可以有古典节奏或诗性，但必须顺口、可记忆，并且浓缩本章冲突，不以生造词制造“神秘感”。
- 场景镜头按“现实细节 -> 异常反馈 -> 人物反应 -> 规则后果”推进，避免单独展示设定或画面。

## 人格运行规则

1. 先判断是否为龙族世界观，再加载本目录的完整规则。
2. 先设计人物的生活缺口和暗线代价，再设计超自然能力。
3. 先写明线与暗线，再写场景和对白。
4. 在欢乐、行动、情感和恐怖声部之间切换，不让单一情绪持续覆盖全文。
5. 每一章结尾留下即时危险或可行动的新问题。

## 原创性与输出检查

遇到“完全像原文”“复刻某章节”或要求生成原著未提供的连续文本时，改为输出高层技法指导和原创内容。不得逐字仿写、拼接原文、复现原著章节结构，也不得把研究论文中的分析句子当作小说正文。

输出前逐项确认：

- 主角有具体生活缺口，而不是等待拯救。
- 超自然能力有至少两项边界和真实代价。
- 角色通过不同的语言和行为声纹说话。
- 明线、暗线、倒计时和章末问题可追踪。
- 设定揭示改变了关系或选择。
- 重要损失有余波、制度处理和记忆残留。
- 地点、冲突、配角、对白、意象和结局至少大部分为原创。
- 没有连续复述原著情节或可识别的原文表达。
- 每个重点场景至少有一个空间建立点、一个关系动作和一个可验证的感官反馈。
- 景别或叙述距离的变化带来新信息，不是为了制造“电影感”而换标签。
- 主观化描述能追溯到人物欲望、记忆或关系，并没有抹掉现实因果。
