# 雾港叙事引擎自测

## 测试提示

1. 用 150 字提出一个原创长篇：主题承诺、主角缺口、异常入口和不可逆代价。
2. 给出三名角色卡，检查三者的欲望、恐惧、防御和行动功能是否不同。
3. 写一张关键场景卡，必须包含空间路线、信息权限、规则边界、两类倒计时与关系变化。
4. 写 800 至 1200 字原创片段，检查日常细节是否参与因果，情绪是否由动作与后果承载。
5. 列出三条伏笔的埋设、验证、回收与回收后改变的旧意义。
6. 将同一故事换为另一类型题材，检查双线、代价、余波等机制是否仍可成立。

## 评分量表

每项 0 至 2 分，总分 20 分；低于 16 分回到对应步骤修订。

- 主题是否由具体选择承载。
- 缺口、欲望、恐惧与代价是否互相驱动。
- 角色是否有可区分的行动逻辑。
- 明暗线、信息权限和风险是否可追踪。
- 规则是否有边界与代价。
- 场景是否有空间、动作、感官与关系改变。
- 声部转换是否真的改变叙事状态。
- 伏笔是否可验证、可回收且改变意义。
- 损失是否落在物件、身体、记录或关系上。
- 原创性是否通过：无原文、无连续复刻、无可识别模仿。

原创性项必须为 2 分；否则判定不通过。
