# 《龙族》1—4 分卷叙事机制蒸馏审计

## 范围与方法

- 素材：`原著素材/龙族/分卷` 的 21 个 UTF-8 文本，实测 6,598,827 B、2,227,691 个字符；卷次分布为 3 / 4 / 11 / 3。
- 覆盖：每卷的开端、转折、行动升级和余波节点；以卷内章节边界、场景功能、信息类型和后果作为定位方式。
- 处理：只记录高层观察与机制摘要，不保留原文摘录、连续情节、台词或可识别句式。
- 判定：至少两组独立样本支撑的模式可进入核心人格；单卷或单段独有装置列为变量。

## 核心生成规则

1. **从缺口进入异常**：触发条件为主角在现实生活中已有不可被口号解决的匮乏；以异常事件迫使其处理一个立即任务；检查其是否同时改变现实判断、关系位置和风险；重做人物、入口和任务。
2. **双线相咬**：明线处理调查/护送/谈判/行动，暗线处理身份、记忆、家庭位置或归属；每次明线升级必须逼近暗线，每次暗线揭示必须改变权限、资源、时间或选择；重做冲突对象与答案。
3. **规则带代价**：超常能力、机构援助、异空间或技术便利均明确范围、媒介、反制或损伤；使用后至少发生一项资源、身体、信任或证据层面的变化；重做规则体系。
4. **关系以动作落地**：用等待、交接、撤回、并行、称谓、座位或遗留物呈现关系重估；不以宣言代替选择；重做关系网和情感结果。
5. **日常细节回收**：先把生活细节写成角色习惯或轻松关系，再在压力下改变其用途；检查回收是否改变选择或旧场景意义；使用原创物件与情境。
6. **多倒计时行动**：行动段同时维护空间路线、通讯/资源状态和时间/风险阈值；失败不可只造成抽象受伤；重做行动目标、地形和失败后果。
7. **余波结算**：高潮结束后处理可见后果并提出更高层问题；禁止以反转取消已发生的损失；重做结局和遗留物。

## 作品特定变量与限制

- 特定神话谱系、术语、角色、组织、地点、标志道具、连续事件和章节标题均不进入人格。
- 第 3 部的地域化家族/城市结构、第 4 部的现实可靠性议题可作为可选压力底色，不应被误当成所有作品的强制模板。
- 关键词出现次数仅用于覆盖核验，不可作为文风公式或因果证据。

## 原创边界

保留以上机制，必须替换人物、地理、机构、规则、关系、线索、物件、对白、行动链、意象和结局。禁止原文复述、连续情节改名、标志性场景顺序复制、可识别模仿指令或现实作者身份扮演。
