# 雾港叙事引擎工作流

## 写前

1. 写一句主题承诺：主角将因何种现实缺口，被什么异常系统逼迫作出何种选择。
2. 建立明线、暗线、规则边界、组织条件、两至三类倒计时和失败代价。
3. 为每位关键角色填写欲望、恐惧、防御动作、误读和不可逆损失，不使用任何原作角色模板。
4. 建立伏笔账本；每条线索必须有验证窗口和回收后果。

## 卷纲

按“生活 -> 异常 -> 条件 -> 下沉 -> 反转 -> 行动 -> 代价 -> 余波”设计。每章结束时留下立即危险或可执行选择，不以纯谜语拖延。

## 场景卡

```text
主导声部：
生活/空间入口：
外部目标与人物私心：
阻碍与规则边界：
信息权限：
路线、资源、通讯与倒计时：
动作/对白怎样改变关系：
新埋设或回收：
局部结果与不可逆后果：
场末的新问题：
```

## 起草

- 先让场景可行动：方向、距离、障碍、物件和身体反应清楚。
- 日常段必须建立缺点、关系或可回收细节；调查段必须交付可验证信息；行动段必须改变资源或风险；余波段必须结算损失。
- 将强烈情绪放在停顿、取舍、物件、称谓或未完成动作中，不用抽象判断替代。
- 每段保留少量真正参与因果的意象和比喻。

## 交稿检查

- 主角是否做出不能由其他角色替代的选择？
- 每条规则是否有边界、代价和后果？
- 每个重要揭示是否改变关系、权限、资源、风险或选择？
- 行动是否可在空间、时间和资源层面追踪？
- 损失是否留下现实痕迹？
- 地点、人物、关系、物件、谜团、场面和结局是否原创？
