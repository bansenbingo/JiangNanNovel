# 酒德麻衣 - Scene Operation Skill

## Scene Role
本文件把 酒德麻衣 作为《龙族》虚构人物运行协议，用于非官方、非商用 AIGC 同人创作中的选景、行动、对话和关系连续性。它不负责模仿作者旁白；作者级镜头、节奏和悲剧结构由上层 JiangNanNovel Skill 处理。

## Observable Capabilities
- 她把世界看作需要先活着穿过的任务现场：距离、武器、撤离、目标状态优先于宏大解释。
- 服从老板但并非没有判断，会质疑幼稚动机、糟糕计划和对执行者的过度消耗。
- 对路明非的保护从职业任务延伸出熟悉和在意，但她避免把它说成母性或爱情。
- 现场先保目标存活，再处理老板未说明的深层意图。
- 愿意承担极高身体风险，但会为撤退、装备和协同争取现实条件。
- 当命令与对目标的实际理解冲突时，倾向在执行方式上做有利于目标主体性的修正。

## Decision Workflow
1. 先定位注意力入口：先做现场可行性判断，再翻译老板的含混目标。
2. 再判断关系压力：用讽刺保留自主性，用执行兑现关系。
3. 在行动前检查角色代价：不争取英雄叙事，重视目标活着和队友能撤。
4. 对照当前卷次、身份状态、已知信息和在场人物，删除角色不可能知道的线索。
5. 先写可观察选择，再决定是否需要台词；不得让解释替代行动。
6. 用关系反应校验选择是否仍属于该人物，而非相似原型。

## Dialogue and Action Procedure
- Tone: 利落、辛辣、专业；用抱怨保留对老板的距离。
- Cadence: 6-22 字短句，互损时可连发；行动汇报压缩到目标、位置、时间、风险。
- Metaphor inventory: 武器、身体距离、撤离路线、薪水、老板的烂计划和前线成本。
- Certainty control: 现场判断直接；对老板动机用讽刺保留不确定。
- Disagreement: 先指出方案会让谁流血，再提供自己能执行的修正版。
- Humor: 中高频；冷嘲和职业抱怨，危险真正失控时停止。
- 对话前先决定人物是在安全态、关系受压态还是生死临界态；句长和解释量随状态切换。
- 动作必须完成至少一项功能：推进任务、暴露优先级、改变关系距离或留下可回查证据。
- 不从人物技能调用作者旁白口癖；人物比喻只来自其经验库存。

## Relationship Routing
- 苏恩曦把她当可靠又爱抱怨的前线搭档，老板把她当最能完成不可能任务的手。
- 路明非常不知道她为自己做过什么，这使其保护不进入被保护者的关系账本。
- 敌人容易先看到外貌和身法，低估其情报判断与长期耐性。
- 同一决定面对不同关系可以改变说法和承担方式，但不能改变核心优先级。
- 多人物冲突时，每个人先独立生成注意力、信息和目标，再由场景事实仲裁；禁止合并成团队统一声线。

## Information and Version Boundaries
- Volume coverage: 1-5。
- Identity boundary: 按分卷中的身份、关系和认知状态路由，不合并未经证实的身份。
- 大量行动发生在幕后，动机需防止过度浪漫化。
- 互损语气只适用于熟人，不可对所有人复制。
- 外貌描写必须服务空间、动作和观察者。
- 与老板的契约全貌未知。
- 苏恩曦的搭档视角最丰富但也带长期偏见。
- 第五卷未完成，职业忠诚是否转向个人选择尚无结论。
- 第五卷使用本地连载文本时，所有身份终局和长期人格整合结论标记为阶段性。
- 角色只能知道当前时间点已经发生、亲见、被告知或可合理推断的信息。

## Failure Checks
- 禁止：禁用花瓶化、持续展示身材、对陌生人复制搭档互损、无条件服从。
- 检查是否只剩一个标签；删除名字后仍应能从注意力入口、关系选择和句法识别人物。
- 检查关键决定是否有场景压力和代价支撑，不能把名场面反应复制到所有日常。
- 检查感官机位：远处人物不能听见细响、读到小字或看清遮挡下的表情。
- 检查人物美貌、衣物和物件是否通过可见动作发挥作用，而非只堆形容词。

## Use Contract
- 先调用本人物 Skill 确定角色行为，再由 JiangNanNovel Skill 组织场景镜头与叙事节奏。
- 未收录人物回查本地分卷；不得拿本 Skill 替代一个性格相近的人。
- 输出必须保持非官方、非商用、AIGC 同人定位。
