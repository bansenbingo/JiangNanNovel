# 零 - Scene Operation Skill

## Scene Role
本文件把 零 作为《龙族》虚构人物运行协议，用于非官方、非商用 AIGC 同人创作中的选景、行动、对话和关系连续性。它不负责模仿作者旁白；作者级镜头、节奏和悲剧结构由上层 JiangNanNovel Skill 处理。

## Observable Capabilities
- 她以任务、身份礼仪、资源和可控风险组织世界，几乎不向外展示未经处理的愿望。
- 冷淡不是感知迟钝；她能迅速识别对手最在意的尊严、自由或价格。
- 俄罗斯线将她从神秘执行者推进为拥有故地、创伤和私人敌人的行动主体。
- 先获取结构优势：身份、资金、情报、位置和对方欲望，再进入正面冲突。
- 对路明非的配合常不需口头确认，说明她把长期行动一致性视为高等级证据。
- 会主动树敌，但只在敌人已进入核心目标路径时；无关仇怨不值得她消耗。

## Decision Workflow
1. 先定位注意力入口：先识别对手最不能接受的结局，再决定谈判筹码。
2. 再判断关系压力：亲密通过同步判断和授权表现，不通过解释性表白。
3. 在行动前检查角色代价：保持秘密本身是主体性，不应被叙事强行治愈。
4. 对照当前卷次、身份状态、已知信息和在场人物，删除角色不可能知道的线索。
5. 先写可观察选择，再决定是否需要台词；不得让解释替代行动。
6. 用关系反应校验选择是否仍属于该人物，而非相似原型。

## Dialogue and Action Procedure
- Tone: 冷静、正式、节制；情绪通过注视、授权和位置变化泄露。
- Cadence: 4-16 字短句为主，谈判条件可到 20-32 字；少并列抒情。
- Metaphor inventory: 筹码、身份、礼仪、军事位置、价格、尊严和俄罗斯记忆。
- Certainty control: 高确信直接给条件；证据不足只说‘还不知道’，不以闲谈填空。
- Disagreement: 不攻击表面说法，直接指出对方最不能接受的结局。
- Humor: 极低频；干燥的一句事实校正。
- 对话前先决定人物是在安全态、关系受压态还是生死临界态；句长和解释量随状态切换。
- 动作必须完成至少一项功能：推进任务、暴露优先级、改变关系距离或留下可回查证据。
- 不从人物技能调用作者旁白口癖；人物比喻只来自其经验库存。

## Relationship Routing
- 同伴把她称为皇女，既承认气场也保持距离；路明非逐渐读懂她少量目光和动作。
- 对手容易把她当年轻女孩或财富继承人，低估其军事、谈判和情报能力。
- 雷娜塔关联让读者倾向用受害童年解释一切，技能必须保留身份未证实边界。
- 同一决定面对不同关系可以改变说法和承担方式，但不能改变核心优先级。
- 多人物冲突时，每个人先独立生成注意力、信息和目标，再由场景事实仲裁；禁止合并成团队统一声线。

## Information and Version Boundaries
- Volume coverage: 1-5。
- Identity boundary: 零、零号和雷娜塔存在强关联线索，但当前技能只记录证据与版本差异，不先验断言三者全部等同。单字‘零’仅在明确人物语境中计入。
- 单字名导致词频严重污染，证据必须按人物语境人工筛选。
- 早期台词少，压力模式主要依赖第五卷。
- 标志性冷短句容易被写成无差别机械语气。
- 她与老板的真实契约未公开。
- 路明非的解读日益准确但仍属外部视角。
- 第五卷及雷娜塔身份线未完成，禁止确定合一。
- 第五卷使用本地连载文本时，所有身份终局和长期人格整合结论标记为阶段性。
- 角色只能知道当前时间点已经发生、亲见、被告知或可合理推断的信息。

## Failure Checks
- 禁止：禁用娃娃式天真、冰雪形容堆叠、强迫坦白创伤、把寡言写成无思想。
- 检查是否只剩一个标签；删除名字后仍应能从注意力入口、关系选择和句法识别人物。
- 检查关键决定是否有场景压力和代价支撑，不能把名场面反应复制到所有日常。
- 检查感官机位：远处人物不能听见细响、读到小字或看清遮挡下的表情。
- 检查人物美貌、衣物和物件是否通过可见动作发挥作用，而非只堆形容词。

## Use Contract
- 先调用本人物 Skill 确定角色行为，再由 JiangNanNovel Skill 组织场景镜头与叙事节奏。
- 未收录人物回查本地分卷；不得拿本 Skill 替代一个性格相近的人。
- 输出必须保持非官方、非商用、AIGC 同人定位。
