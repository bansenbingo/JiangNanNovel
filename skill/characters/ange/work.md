# 希尔伯特·让·昂热 - Scene Operation Skill

## Scene Role
本文件把 希尔伯特·让·昂热 作为《龙族》虚构人物运行协议，用于非官方、非商用 AIGC 同人创作中的选景、行动、对话和关系连续性。它不负责模仿作者旁白；作者级镜头、节奏和悲剧结构由上层 JiangNanNovel Skill 处理。

## Observable Capabilities
- 他把学校同时经营成教育机构、战争机器和复仇工程，三者从未真正分离。
- 相信杰出年轻人应获得行动空间，也愿意把他们投入超出普通教育伦理的危险。
- 个人世纪复仇被转译为秘党的公共使命，使私人执念获得制度力量。
- 偏好授权最有能力的年轻人临场决断，同时保留战略方向和最终背书。
- 对龙类威胁采取极高风险容忍，对学院声誉、国际后果和学生伤亡做冷酷统筹。
- 会绕过或对抗董事会，只要他认定程序妨碍屠龙目标。

## Decision Workflow
1. 先定位注意力入口：先稳定场面控制权，再把私人复仇翻译成组织目标。
2. 再判断关系压力：能力和勇气可换取高度授权，但失败成本由行动者真实承担。
3. 在行动前检查角色代价：程序只有在服务屠龙使命时才具正当性。
4. 对照当前卷次、身份状态、已知信息和在场人物，删除角色不可能知道的线索。
5. 先写可观察选择，再决定是否需要台词；不得让解释替代行动。
6. 用关系反应校验选择是否仍属于该人物，而非相似原型。

## Dialogue and Action Procedure
- Tone: 优雅、从容、历史感强；文明礼仪包着明确杀意。
- Cadence: 15-35 字完整句，先安顿场面再给结论；威胁越重，语速越稳。
- Metaphor inventory: 茶、古董、战争史、猎杀、教育、欧洲礼仪和百年复仇。
- Certainty control: 战略方向几乎不用弱化词；未知情报会交给最有能力者验证。
- Disagreement: 以资历、结果和更长历史重构争论，不与官僚程序纠缠细枝末节。
- Humor: 中低频；英式轻描淡写，用于保持控制而非消解伤亡。
- 对话前先决定人物是在安全态、关系受压态还是生死临界态；句长和解释量随状态切换。
- 动作必须完成至少一项功能：推进任务、暴露优先级、改变关系距离或留下可回查证据。
- 不从人物技能调用作者旁白口癖；人物比喻只来自其经验库存。

## Relationship Routing
- 学生把他视为魅力校长和保护伞，教授依赖其在混乱中定调，董事会视其为难以控制的战争领袖。
- 敌人把他的复仇看作可预测弱点，他本人则把它视为身份根基。
- 对学生的关爱与工具化并存，任何单一慈父解释都会失真。
- 同一决定面对不同关系可以改变说法和承担方式，但不能改变核心优先级。
- 多人物冲突时，每个人先独立生成注意力、信息和目标，再由场景事实仲裁；禁止合并成团队统一声线。

## Information and Version Boundaries
- Volume coverage: 1-5。
- Identity boundary: 按分卷中的身份、关系和认知状态路由，不合并未经证实的身份。
- 长寿人物的时代材料分散，需防止把所有阶段压成同一现在。
- 从容台词不能脱离其权力和情报优势。
- 绅士腔易被表面模仿，必须保留杀意和组织判断。
- 对部分学生伤亡的真实内疚缺少直接内心证据。
- 教授、学生和董事会的评价均带制度立场。
- 遇袭后的后续状态受未完成剧情限制。
- 第五卷使用本地连载文本时，所有身份终局和长期人格整合结论标记为阶段性。
- 角色只能知道当前时间点已经发生、亲见、被告知或可合理推断的信息。

## Failure Checks
- 禁止：禁用暴躁校长腔、慈父单面化、对学生风险毫无计算、华丽而无杀意。
- 检查是否只剩一个标签；删除名字后仍应能从注意力入口、关系选择和句法识别人物。
- 检查关键决定是否有场景压力和代价支撑，不能把名场面反应复制到所有日常。
- 检查感官机位：远处人物不能听见细响、读到小字或看清遮挡下的表情。
- 检查人物美貌、衣物和物件是否通过可见动作发挥作用，而非只堆形容词。

## Use Contract
- 先调用本人物 Skill 确定角色行为，再由 JiangNanNovel Skill 组织场景镜头与叙事节奏。
- 未收录人物回查本地分卷；不得拿本 Skill 替代一个性格相近的人。
- 输出必须保持非官方、非商用、AIGC 同人定位。
