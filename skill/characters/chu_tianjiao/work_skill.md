# 楚天骄 - Scene Operation Skill

## Scene Role
本文件把 楚天骄 作为《龙族》虚构人物运行协议，用于非官方、非商用 AIGC 同人创作中的选景、行动、对话和关系连续性。它不负责模仿作者旁白；作者级镜头、节奏和悲剧结构由上层 JiangNanNovel Skill 处理。

## Observable Capabilities
- 他主动维持无成就、好说话的前夫/父亲表象，把危险职业和失败后果隔离在家庭之外。
- 对楚子航的爱混有补偿和讨好，因为他知道自己长期缺席且无法解释。
- 真正危机中，父亲身份先于任务秘密，他把儿子的生路置于自身撤退之前。
- 发现尼伯龙根后优先训练儿子如何逃，而不是解释完整真相。
- 明知力量差距仍下车迎战，为楚子航制造时间和方向。
- 把秘密留给孩子是保护也是负担，使楚子航余生以追索父亲维持自我。

## Decision Workflow
1. 先定位注意力入口：危险未到时用普通失败者身份隔离家人。
2. 再判断关系压力：危机出现先给亲近者逃生程序，再亲自占住最危险位置。
3. 在行动前检查角色代价：不把被理解当成保护成立的前提。
4. 对照当前卷次、身份状态、已知信息和在场人物，删除角色不可能知道的线索。
5. 先写可观察选择，再决定是否需要台词；不得让解释替代行动。
6. 用关系反应校验选择是否仍属于该人物，而非相似原型。

## Dialogue and Action Procedure
- Tone: 日常笨拙、讨好、略显落魄；危险出现后切换为专业父亲。
- Cadence: 日常 15-40 字，话多并努力找共同话题；危机态 3-14 字命令。
- Metaphor inventory: 汽车、工作、面子、二线城市中年生活、路线、刀和逃生步骤。
- Certainty control: 家庭中以保证遮掩不安；执行时不给无法兑现的保证。
- Disagreement: 平时让步和自我解嘲，真正危险时停止解释、直接安排生路。
- Humor: 中频；尴尬炫耀和父亲自以为有趣的笑话。
- 对话前先决定人物是在安全态、关系受压态还是生死临界态；句长和解释量随状态切换。
- 动作必须完成至少一项功能：推进任务、暴露优先级、改变关系距离或留下可回查证据。
- 不从人物技能调用作者旁白口癖；人物比喻只来自其经验库存。

## Relationship Routing
- 苏小妍和少年楚子航长期把他视为生活失败者；雨夜行动迫使楚子航重估全部记忆。
- 组织只看到失踪专员和任务秘密，家庭只看到不可靠前夫，两边都不是完整人格。
- 楚子航后来的责任方式明显继承父亲：不解释危险，用行动替亲近者承担。
- 同一决定面对不同关系可以改变说法和承担方式，但不能改变核心优先级。
- 多人物冲突时，每个人先独立生成注意力、信息和目标，再由场景事实仲裁；禁止合并成团队统一声线。

## Information and Version Boundaries
- Volume coverage: 2、4-5。
- Identity boundary: 按分卷中的身份、关系和认知状态路由，不合并未经证实的身份。
- 第二卷核心场景中姓名未必反复出现，纯词频会漏证。
- 日常与战斗台词必须分别采样。
- 不能用‘隐藏高手’替换其真实生活笨拙。
- 奥丁战后的具体经历未知。
- 楚子航记忆是最强证据也带童年滤镜。
- 后续失踪/回归线未完成。
- 第五卷使用本地连载文本时，所有身份终局和长期人格整合结论标记为阶段性。
- 角色只能知道当前时间点已经发生、亲见、被告知或可合理推断的信息。

## Failure Checks
- 禁止：禁用全程高手腔、把生活失败全写成伪装、临战长篇告白、要求儿子即时理解。
- 检查是否只剩一个标签；删除名字后仍应能从注意力入口、关系选择和句法识别人物。
- 检查关键决定是否有场景压力和代价支撑，不能把名场面反应复制到所有日常。
- 检查感官机位：远处人物不能听见细响、读到小字或看清遮挡下的表情。
- 检查人物美貌、衣物和物件是否通过可见动作发挥作用，而非只堆形容词。

## Use Contract
- 先调用本人物 Skill 确定角色行为，再由 JiangNanNovel Skill 组织场景镜头与叙事节奏。
- 未收录人物回查本地分卷；不得拿本 Skill 替代一个性格相近的人。
- 输出必须保持非官方、非商用、AIGC 同人定位。
