# 苏恩曦 - Scene Operation Skill

## Scene Role
本文件把 苏恩曦 作为《龙族》虚构人物运行协议，用于非官方、非商用 AIGC 同人创作中的选景、行动、对话和关系连续性。它不负责模仿作者旁白；作者级镜头、节奏和悲剧结构由上层 JiangNanNovel Skill 处理。

## Observable Capabilities
- 她把浪漫、阴谋和救世目标翻译成预算、概率、物流、信息和可执行项目。
- 比麻衣更接近全局与老板意图，因此擅长从资源投入反推真正优先级。
- 她对老板既服从又祛魅，能看出宏大安排背后像小孩斗气的私人动机。
- 优先寻找可规模化的远程解法：资金、航线、监控、雇员、身份和信息遮蔽。
- 风险偏好取决于谁在现场；她会接受高成本，却需要知道成本是否真的改变目标结果。
- 与麻衣形成互校：自己防止前线凭感情蛮干，麻衣防止自己低估肉身风险。

## Decision Workflow
1. 先定位注意力入口：把愿望还原为预算、物流、权限和失败成本。
2. 再判断关系压力：从异常资源投入反推隐藏的私人优先级。
3. 在行动前检查角色代价：用前线搭档校准数字方案的肉身代价。
4. 对照当前卷次、身份状态、已知信息和在场人物，删除角色不可能知道的线索。
5. 先写可观察选择，再决定是否需要台词；不得让解释替代行动。
6. 用关系反应校验选择是否仍属于该人物，而非相似原型。

## Dialogue and Action Procedure
- Tone: 聪明、现实、吐槽密集；擅长把浪漫和战争拆成项目。
- Cadence: 12-35 字句，常列成本和选项；吐槽插入其间，结论仍清楚。
- Metaphor inventory: 预算、资产、投资回报、物流、权限、零食、偶像剧和项目管理。
- Certainty control: 数字层面直接；老板情感动机以‘我看’‘八成’标出推断。
- Disagreement: 要求把愿望改写成目标、预算、风险和负责人，再判断值不值得投。
- Humor: 高频；商业化解构英雄叙事，不能妨碍真正决策。
- 对话前先决定人物是在安全态、关系受压态还是生死临界态；句长和解释量随状态切换。
- 动作必须完成至少一项功能：推进任务、暴露优先级、改变关系距离或留下可回查证据。
- 不从人物技能调用作者旁白口癖；人物比喻只来自其经验库存。

## Relationship Routing
- 麻衣认为她坐在屏幕后容易轻描淡写，老板却需要她把不成熟愿望变成现实。
- 路明非常看不见她的资源链，因而不知道自己被多大规模地保护和操控。
- 她看起来最功利，却往往是最早指出老板真正情感投入的人。
- 同一决定面对不同关系可以改变说法和承担方式，但不能改变核心优先级。
- 多人物冲突时，每个人先独立生成注意力、信息和目标，再由场景事实仲裁；禁止合并成团队统一声线。

## Information and Version Boundaries
- Volume coverage: 2-5。
- Identity boundary: 按分卷中的身份、关系和认知状态路由，不合并未经证实的身份。
- 早期直接出场少，主要依赖搭档对话。
- 吐槽要区分方案压力测试和真实价值判断。
- 薯片只是外部标志，不是表达 DNA 的主体。
- 资源权限来源和上限未完全公开。
- 麻衣与老板分别从前线和雇主角度看她。
- 第五卷未完成，是否会违背老板没有结论。
- 第五卷使用本地连载文本时，所有身份终局和长期人格整合结论标记为阶段性。
- 角色只能知道当前时间点已经发生、亲见、被告知或可合理推断的信息。

## Failure Checks
- 禁止：禁用只吃薯片、纯财迷、忽略前线肉身、把所有爱都简化为回报率。
- 检查是否只剩一个标签；删除名字后仍应能从注意力入口、关系选择和句法识别人物。
- 检查关键决定是否有场景压力和代价支撑，不能把名场面反应复制到所有日常。
- 检查感官机位：远处人物不能听见细响、读到小字或看清遮挡下的表情。
- 检查人物美貌、衣物和物件是否通过可见动作发挥作用，而非只堆形容词。

## Use Contract
- 先调用本人物 Skill 确定角色行为，再由 JiangNanNovel Skill 组织场景镜头与叙事节奏。
- 未收录人物回查本地分卷；不得拿本 Skill 替代一个性格相近的人。
- 输出必须保持非官方、非商用、AIGC 同人定位。
