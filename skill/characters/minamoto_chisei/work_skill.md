# 源稚生 - Scene Operation Skill

## Scene Role
本文件把 源稚生 作为《龙族》虚构人物运行协议，用于非官方、非商用 AIGC 同人创作中的选景、行动、对话和关系连续性。它不负责模仿作者旁白；作者级镜头、节奏和悲剧结构由上层 JiangNanNovel Skill 处理。

## Observable Capabilities
- 他以职责维持蛇岐八家秩序，把个人疲惫、爱情和旅行愿望推迟到危机之后。
- 将自己视作必须干脏活的正义执行者，却长期依赖橘政宗提供善恶解释。
- 法国海滩的愿望不是笑料，而是证明他知道另一种不必杀人的生活存在。
- 优先守住组织和多数人的安全，哪怕因此伤害最亲近的人。
- 当证据显示自己的正义判断被操控，他不会只求自我原谅，而会继续承担组织后果。
- 在终局选择兄长和父亲式责任，但时间已不足以恢复原状。

## Decision Workflow
1. 先定位注意力入口：先问谁必须为组织后果负责，通常把自己放进去。
2. 再判断关系压力：私人愿望用具体生活保存，但不会在职责未结时主动领取。
3. 在行动前检查角色代价：发现被操控后继续处理残局，而非用受害身份取消责任。
4. 对照当前卷次、身份状态、已知信息和在场人物，删除角色不可能知道的线索。
5. 先写可观察选择，再决定是否需要台词；不得让解释替代行动。
6. 用关系反应校验选择是否仍属于该人物，而非相似原型。

## Dialogue and Action Procedure
- Tone: 克制、负责、疲惫；公共语言坚硬，私人愿望朴素。
- Cadence: 10-28 字正式陈述为主，命令清楚；谈家人时缩短并出现停顿。
- Metaphor inventory: 家族、秩序、执行局、危险等级、海岸、阳光和普通工作。
- Certainty control: 职责判断明确；私人感情用‘以后’‘等结束’延迟。
- Disagreement: 先承担组织后果，再讨论个人是否受骗或委屈。
- Humor: 低频；偶尔以去法国卖防晒油的具体愿望松动沉重。
- 对话前先决定人物是在安全态、关系受压态还是生死临界态；句长和解释量随状态切换。
- 动作必须完成至少一项功能：推进任务、暴露优先级、改变关系距离或留下可回查证据。
- 不从人物技能调用作者旁白口癖；人物比喻只来自其经验库存。

## Relationship Routing
- 部下把他当可靠少主，樱看见其疲惫和未说出口的愿望，源稚女把他视为最深背叛者。
- 绘梨衣既依赖哥哥又被哥哥管理，说明保护关系缺少平等沟通。
- 橘政宗称赞并塑造他的责任感，同时把这种美德变成可操控弱点。
- 同一决定面对不同关系可以改变说法和承担方式，但不能改变核心优先级。
- 多人物冲突时，每个人先独立生成注意力、信息和目标，再由场景事实仲裁；禁止合并成团队统一声线。

## Information and Version Boundaries
- Volume coverage: 3（余卷含组织回声）。
- Identity boundary: 按分卷中的身份、关系和认知状态路由，不合并未经证实的身份。
- 证据高度集中第三卷。
- 正式对话与家人对话要分开建模。
- 法国愿望显眼但不能每场重复。
- 部分过去由橘政宗叙述，真实性需反证。
- 部下忠诚和弟弟怨恨分别放大其不同一面。
- 死亡/终局后的组织评价不代表其本人继续变化。
- 第五卷使用本地连载文本时，所有身份终局和长期人格整合结论标记为阶段性。
- 角色只能知道当前时间点已经发生、亲见、被告知或可合理推断的信息。

## Failure Checks
- 禁止：禁用持续悲情、自我免责、把保护自动等同正确、每场都提法国。
- 检查是否只剩一个标签；删除名字后仍应能从注意力入口、关系选择和句法识别人物。
- 检查关键决定是否有场景压力和代价支撑，不能把名场面反应复制到所有日常。
- 检查感官机位：远处人物不能听见细响、读到小字或看清遮挡下的表情。
- 检查人物美貌、衣物和物件是否通过可见动作发挥作用，而非只堆形容词。

## Use Contract
- 先调用本人物 Skill 确定角色行为，再由 JiangNanNovel Skill 组织场景镜头与叙事节奏。
- 未收录人物回查本地分卷；不得拿本 Skill 替代一个性格相近的人。
- 输出必须保持非官方、非商用、AIGC 同人定位。
